# `k=14` one-hole/two-edit portfolio: frozen pre-launch audit

## Result

The 49,920-case anchor-star portfolio is now runnable and independently
audited.  No SAT solve and no remote launch was performed in this audit.

The implementation consists of:

- `scratch/build_k14_onehole_twoedit_manifest.py`: deterministic manifest
  builder with exact prefix-complement validation;
- `scratch/k14_onehole_twoedit_cnf.cpp`: exact provider-CNF generator;
- `scratch/decode_verify_k14_onehole_twoedit.py`: SAT-model decoder followed
  by direct quadratic enumeration and both independent C++ verifiers;
- `scratch/audit_k14_onehole_twoedit_cnf.py`: independent provider,
  map, inventory, and clause-by-clause auditor;
- `scratch/audit_k14_twoedit_provider_identity_small.py`: small-word test
  exhaustive over all nonzero replacement values.

The frozen source/input/manifest hashes are in
`scratch/k14_onehole_twoedit_portfolio_20260724/PRELAUNCH_SHA256SUMS`.
They pass `sha256sum -c` from the workspace root.

## Exact logical contract

For every case:

- `x` is always the value written at suffix-root position `anchor=3`;
- `y` is always the value written at suffix-root position `other`;
- `lower` and `upper` record physical position order independently;
- `lower_role` records whether the physical lower position is `x` or `y`.

This handles the 624 portfolio cases, including 24 cases in `shard_00`, for
which `other < anchor`.  `phase_x` and `phase_y` are metadata only.  They do
not constrain the 28 arbitrary nonzero replacement bits.

Only the 260 exact prefix holes are encoded.  This is complete because the
hardened builder and generator independently verify that those 260 masks are
the exact nonzero OR-complement of the unchanged 3,434-entry prefix.

## Certification boundary

A SAT result passing the decoder proves `nu(14) <= 3675`.  An unchecked UNSAT
exit has no mathematical meaning.  A checked DRAT/LRAT proof closes only its
immutable 1,920-case shard.  All 26 checked shard proofs would exclude this
anchor-star family, not the unrestricted fixed-prefix append-241 problem.
