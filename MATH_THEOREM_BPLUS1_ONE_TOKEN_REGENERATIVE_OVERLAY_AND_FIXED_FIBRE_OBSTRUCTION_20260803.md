# A one-token regenerative overlay for the `B+1` pivot route

**Date:** 2026-08-03  
**Status:** exact state-compression and conditional same-parity induction
theorem.  The scalar/deadline step, the local pivot, the component-port
min--max, and the one-coordinate diagonal router are unconditional inputs.
The fresh protected host, all-width/residence renewal, and the remaining
two-coordinate common-cap linkage are explicit hypotheses.  No
unconditional `B(k)+O(1)` bound is claimed.

## 0. Outcome

For odd dimension

\[
 k_m=2m-1,\qquad r_m=m,\qquad
 W_m={2m-1\choose m},\qquad B_m=W_m+d_m,
\]

the exact Pascal scalar recurrence gives

\[
                         d_{m+1}-d_m\in\{0,1\}.       \tag{0.1}
\]

The sharp one-aperture pivot consequently has a genuinely bounded
**logical overlay** on top of the full integral Pascal payload.  On the
child-native reconstruction face, the additional protected interface is one
named set

\[
                    H_m\in { [2m-1]\choose m-1}.      \tag{0.2}
\]

It is a structured token, not a constant-bit object.  Its arity is one.
This does not say that the entire parent factor or its chain partition can
be discarded; those remain the core induction object.  The assertion is
that the extra pivot/topology/router boundary state has arity one.

After adjoining two fresh coordinates, one fresh tag raises `H_m` to the
correct child rank.  The one-in/one-out pivot theorem realizes that tagged
set as the incoming exact-width colour and exports exactly one new colour
`H_(m+1)`.  If the pivot aperture is the global opened seam, then this same
outgoing colour is simultaneously

1. the unique lower-`q1` colour omitted by the Hamilton path;
2. the pivot's unique locally unrealized colour; and
3. the unique wrap port lost when the cyclic diagonal-diamond router is
   opened linearly.

Hence one occurrence-labelled exterior boundary bundle can discharge all
three roles.  There is no second boundary ticket and no positive-threshold
sorting state.

This yields an exact conditional induction.  If every incoming token has a
fresh child host satisfying

* the prescribed-endpoint component-port Hall condition;
* protected octagon accessibility (or a direct ordered connector forest);
* all-width and residence renewal;
* the coalesced boundary bundle; and
* a two-coordinate common-cap deficiency at most a fixed `C`, with at most
  `C` omitted named tickets regenerated rather than accumulated,

then

\[
                         \nu(2m-1)\le B_m+1+C          \tag{0.3}
\]

for all sufficiently large `m`.  At `C=0`, the recursive sidecar consists
only of the single token (0.2), and the word-length charge is exactly one.

There is also a sharp negative conclusion.  On a fixed rooted connector
fibre, component-port deficiency greater than one is invariant under every
exact port-preserving palette switch and forbids a Hamilton path.  If only
closed `C6` actuators are allowed, component parity is an additional
invariant.  Thus the recurrence must reselect the child rooted fibre or
carry an honest odd actuator; scalar and palette recurrences alone cannot
regenerate topology.

## 1. The one-token state

Let `Omega_m` be the current ground set.  Relative to one complete integral
parent payload, a **logical one-token overlay state** is

\[
                         \Sigma_m=(H_m,E_m),            \tag{1.1}
\]

where

\[
 H_m\in{\Omega_m\choose r_m-1},\qquad |E_m|\le C.     \tag{1.2}
\]

Here `H_m` is the aperture/linear-boundary token.  The finite set `E_m`
contains the named logical tickets omitted by the terminal common-cap
selection.  The case `C=0` has no compiler sidecar.

The state does **not** retain

* a literal suffix word of length `d_m`;
* the old component list or connector matching;
* a permutation of positive ray thresholds;
* the old packet's shared-coordinate birth ledger; or
* a frozen realization of the common-cap linkage.

Those objects are rebuilt child-natively.  This distinction is essential:
the inherited split-core packet has a finite residence horizon, and an
unrestricted exact crossing interface has factorially many equivalence
classes.  The state (1.1) is therefore a reconstruction quotient, not a
lossless summary of arbitrary literal transport.

## 2. Exact rank lift and one-in/one-out relay

Write

\[
 r=r_m=m,\qquad d=d_m,
\]

and let the child have

\[
 r'=r+1,\qquad d'=d_{m+1}\in\{d,d+1\}.               \tag{2.1}
\]

Adjoin fresh coordinates `x,y` and define

\[
                         \widehat H=H_m\cup\{x\}.      \tag{2.2}
\]

Then `widehat H` has rank `r'-1`, exactly the incoming rank required by the
child aperture theorem.

### Theorem 2.1 (one-token pivot relay)

For every sufficiently large `m` and every `H_m` in (1.2), a fresh sharp
aperture block at parameters `(r',d')` can be chosen so that its incoming
full fan is `widehat H` and its unique outgoing aperture colour is some

\[
                         H_{m+1}\in
                         {\Omega_m\cup\{x,y\}\choose r'-1}.       \tag{2.3}
\]

The local debt count is exactly one before and after the relay.  The block
uses one star cell, preserves every old interval-OR value under its
insertion, and its local lower compiler is neutral after the prescribed ray
reassignment.

### Proof

The exact scalar recurrence gives (2.1).  The child ground has size
`2r'-1`, so the complement of `widehat H` has size `r'`.  The one-in/one-out
aperture theorem needs `d'+1` coordinates outside `widehat H`; these exist
once `r'>=d'+2`, which holds for all sufficiently large `m` because
`d'=Theta(sqrt(m))`.

Partition `widehat H=B_0 dotcup Lambda` with

\[
 |B_0|=r'-d',\qquad |\Lambda|=d'-1,
\]

choose `alpha in B_0`, and set `X=B_0-{alpha}`.  The explicit pivot then
has incoming full fan

\[
                         N=X\cup\{\alpha\}\cup\Lambda
                          =\widehat H.                 \tag{2.4}
\]

Its opposite full fan is `Q'=X union rho[1,d'-1]` and the unique missing
native intersection is

\[
                         H_{m+1}=Q'\cup\{\alpha\}.     \tag{2.5}
\]

The sharp pivot and compiler-neutrality theorems give the remaining
claims.  There is one incoming value in (2.4) and one outgoing value in
(2.5), so the debt count remains one.  \(\square\)

The fresh tag in (2.2) may be chosen as part of the child Pascal sector.
No literal copy of the parent packet is needed.  Thus the finite residence
horizon of the inherited shared-bank construction does not apply to this
fresh relay.

### Theorem 2.2 (exact token-transition sphere)

Fix child owner rank `R` and depth `D`, with `R>=D+2`, and fix an incoming
token

\[
                         H\in{[2R-1]\choose R-1}.      \tag{2.6}
\]

The set of outgoing tokens obtainable from the one-in/one-out aperture
relay is exactly

\[
 \mathcal S_D(H)=
 \left\{J\in{[2R-1]\choose R-1}:
                 |H\cap J|=R-D\right\}.              \tag{2.7}
\]

Equivalently, the aperture replaces exactly `D-1` coordinates of `H` by
`D-1` coordinates of its complement.  In particular,

\[
                         |\mathcal S_D(H)|
 = {R-1\choose D-1}{R\choose D-1}.                   \tag{2.8}
\]

### Proof

In the relay proof, write

\[
 H=B_0\mathbin{\dot\cup}\Lambda,qquad
 |B_0|=R-D,qquad |\Lambda|=D-1.                     \tag{2.9}
\]

After choosing `alpha in B_0`, one has `X=B_0-{alpha}`.  If `P` is the
chosen `(D-1)`-set of fresh `rho` coordinates outside `H`, then the output
is

\[
                         J=X\cup P\cup\{\alpha\}
                           =B_0\cup P.                \tag{2.10}
\]

Thus every output satisfies (2.7).

Conversely, let `J` satisfy (2.7).  Take

\[
 B_0=H\cap J,qquad \Lambda=H-J,qquad P=J-H.         \tag{2.11}
\]

These sets have the sizes in (2.9)--(2.10).  Choose `alpha in B_0` and use
the elements of `P` as the ordered `rho` bank.  The complement of `H` has
size `R`; after reserving `P`, it has `R-D+1>=3` elements left, enough for
the two exterior labels `ell,mu` (and one spare).  Hence the literal pivot
construction realizes `J`.  Counting the independently chosen deleted and
inserted banks gives (2.8).  \(\square\)

### Corollary 2.3 (no token-orbit obstruction)

For fixed `R>=D+2` and `D>=2`, the graph on
`binom([2R-1],R-1)` joining two tokens exactly when they satisfy (2.7) is
connected.

### Proof

Put `K=R-1` and `s=D-1`; then `1<=s<=K-2`.  It is enough to realize every
ordinary one-swap Johnson edge by a length-two path in the exact-`s` graph.
Let

\[
 B=A-\{a\}+\{b\},\qquad |A|=|B|=K.                  \tag{2.12}
\]

Choose `K-s-1` elements from `A cap B`, include both `a,b`, and add `s-1`
elements outside `A union B`.  The resulting `K`-set `C` exists because

\[
 |A\cap B|=K-1,qquad
 |[2R-1]-(A\cup B)|=K,                               \tag{2.13}
\]

and `s<=K-2`.  Both `A cap C` and `B cap C` have size `K-s`, so `A-C-B`
is a two-edge path of the required exact distance.  The ordinary Johnson
graph is connected, hence so is the exact-`s` graph.  \(\square\)

This is a local token statement.  It does not prove that the protected
host accepts every edge of the token graph.  It does show that the pivot
algebra contributes no additional orbit invariant: any token obstruction
must come from the correlated host, cap, or occurrence guards.

### Corollary 2.4 (exact bounded-bank avoidance)

Let `F` be a forbidden coordinate set.  There is an outgoing token
`J in mathcal S_D(H)` with `J cap F=emptyset` if and only if

\[
 |H-F|\ge R-D,
 \qquad
 |([2R-1]-H)-F|\ge D-1.                              \tag{2.14}
\]

Equivalently,

\[
 |F\cap H|\le D-1,
 \qquad
 |F-H|\le R-D+1.                                     \tag{2.15}
\]

In particular, every forbidden bank of fixed cardinality is avoidable in
one relay for all sufficiently large `R` on the triangular depth schedule.

### Proof

An output has the form `J=B_0 dotcup P`, where `B_0` is an `(R-D)`-subset
of `H` and `P` is a `(D-1)`-subset of its complement.  It avoids `F`
exactly when both subsets can be selected outside `F`, which is (2.14).
Subtracting from the two shore sizes `R-1,R` gives (2.15).  Along the
triangular schedule, both `D-1` and `R-D+1` tend to infinity.  \(\square\)

Thus no fixed-size coordinate-collision bank needs to be carried forever
inside the token.  This does not avoid occurrence, cap, or component-port
constraints which depend on the complete host rather than only on the set
of token coordinates.

## 3. Boundary coalescence

Consider a cyclic `q1`-exact owner chronology

\[
 T_0,T_1,\ldots,T_{W-1}
\]

with

\[
 P_i=T_i\cap T_{i+1},\qquad R_i=T_i\cup T_{i+1},       \tag{3.1}
\]

indices cyclic.  Assume the literal diagonal identities

\[
 p_i=[i+1,i+d],\quad o_i=[i,i+d],\quad
 q_i=[i,i+d+1]                                        \tag{3.2}
\]

hold, so `p_i-o_i-q_i` and `p_i-o_(i+1)-q_i` are the two
interval-diamond routes.

Open the owner cycle at seam `i_*`.  The resulting linear path uses all
owners and every lower colour except

\[
                              P_{i_*}.                 \tag{3.3}
\]

All diagonal routes except the wrap route with entry `p_(i_*)` remain
interior linear routes.

### Theorem 3.1 (one boundary ticket serves three roles)

Suppose the sharp pivot is planted with its aperture transition at seam
`i_*` and

\[
                         H_{m+1}=P_{i_*}.              \tag{3.4}
\]

Then the following three obligations have the same logical lower label:

1. the unique omitted lower-`q1` colour of the owner path;
2. the unique locally unrealized aperture colour; and
3. the entry label of the unique missing wrap diamond.

Consequently, if one exterior occurrence-labelled complete bundle has
entry value `H_(m+1)`, terminates at the accepted upper-turn occurrence
`q_(i_*)`, and passes the same cap/guard state, that one bundle discharges
all three obligations.  The boundary overlay exports one token, not three.

### Proof

A `W`-owner path has `W-1` internal transitions.  Since the cyclic lower
palette in (3.1) is exact, opening seam `i_*` removes exactly `P_(i_*)`
and no other lower colour.  The one-aperture theorem identifies the
unrealized pivot colour with the set intersection of the opened aperture
transition, which is (3.4).  Finally the diagonal router indexes its port
at seam `i` by the same physical lower interval `p_i` and value `P_i`.
Linear opening removes only the wrap route at `i_*`.  Hence the three
logical labels coincide.

The last assertion is occurrence-level rather than value-level: it assumes
one complete boundary bundle with the stated entry and terminal.  Once that
bundle exists, assigning it once supplies the omitted palette occurrence,
the aperture's exterior occurrence, and the missing route; none of these
roles assigns a different value to the same cell.  \(\square\)

Without (3.4), the aperture theorem itself gives two different boundary
colours: its internal missing colour and the globally omitted path colour.
Thus alignment at the opened seam is the exact state-compression step.

## 4. Topology is a fresh-host acceptance test

Let `Q_0` be a rooted upper-exact Catalan forest containing the forced pivot
bank, with forced pivot arcs contracted.  Let

\[
                         B=(\mathcal C^{out},\mathcal C^{in};E)          \tag{4.1}
\]

be its literal component-port graph.  Let `S,T` be the components required
by the opened pivot orientation, and put

\[
                         B_{S,T}=B-\{T^{out},S^{in}\}.                  \tag{4.2}
\]

### Proposition 4.1 (fresh-host topology criterion)

If `B_(S,T)` has a perfect matching for which every resulting directed
cycle is serially accessible by a pivot-disjoint, all-width-safe quaternary
Boolean octagon, then the child has a protected Hamilton owner path from
`S` to `T`.  No component list, connector permutation, or parity bit need
be exported to the next child.

### Proof

The prescribed-endpoint component-port theorem turns a perfect matching of
`B_(S,T)` into one `S`-to-`T` path plus directed cycles.  Each protected
octagon absorbs one cycle into the path, preserves both immediate palettes,
and retains the endpoints.  Iteration gives the Hamilton path.  Since the
next child reselects a fresh rooted forest and fresh connector matching,
the old component decomposition is sealed and is not recursive data.
\(\square\)

The direct ordered-Hall alternative may replace the octagon hypothesis: a
perfect matching in one forward graph `B_(S,T)^prec` is already the desired
Hamilton path.

### Proposition 4.2 (fixed-fibre obstruction)

Suppose instead that the rooted forest, its free ports, and the allowed
port graph `B` are held fixed, and only exact tail/head/palette-preserving
connector switches are allowed.  Then:

1. if `delta(B)>1`, no such switch sequence can produce one Hamilton path;
2. the number of path components is invariant under every equal-size
   port-preserving switch; and
3. if only closed `C6` switches are available, total component parity is
   invariant, so an even-component opened factor cannot be reduced to one
   component.

### Proof

Hall gives maximum connector size `|mathcal C|-delta(B)`.  Hence one path
plus cycles exists only if `delta(B)<=1`.  Exact port-preserving switches
retain the outgoing and incoming port multisets and the number of selected
arcs.  The identity

\[
             \#\{\text{directed path components}\}
               =|\mathcal C|-|A|                      \tag{4.3}
\]

proves invariance.  A closed `C6` composes the factor permutation with a
3-cycle, an even permutation, and therefore preserves component parity.
\(\square\)

Thus `delta(B)` is not a sidecar that a bounded local pivot can pay.  It is
a host-selection obstruction.  Regeneration must reselect `Q_0,B`, or
leave the fixed fibre with an explicitly priced correlated exchange.

## 5. Common-cap sidecar

Fix one materialized cap/guard/occurrence state.  Let `I` be the logical
terminal ticket set and let the two physical occurrence systems have Rado
matroids `R_0,R_1`.  Their exact common deficiency is

\[
 \delta_{cap}=
 \max_{J_0\cap J_1=\varnothing}
 \left(
 |J_0|-r_{N_0}(A_0(J_0))
 +|J_1|-r_{N_1}(A_1(J_1))
 \right).                                             \tag{5.1}
\]

The diagonal-diamond theorem supplies full rank for one occurrence
coordinate on all interior ports, and Theorem 3.1 coalesces its sole linear
boundary port with `H_(m+1)`.  This does **not** by itself close the second
occurrence coordinate or the transported background.

Assume the remaining system has global product closure, all shared
capacities are allocated, and

\[
                              \delta_{cap}\le C.       \tag{5.2}
\]

Choose a maximum common independent set and put the omitted ticket labels
in `E_(m+1)`.  Then

\[
                              |E_{m+1}|\le C.          \tag{5.3}
\]

Equation (5.3) is the only compiler quantity exported.  It is not enough
that every port has an individual suffix or that an abstract regular
factor exists.  A proof of (5.2) must supply the exact all-subset/all-cut
Rado inequalities, or a capacity-faithful direct-flow certificate, in the
same materialized state.

## 6. The reset-host hypothesis

For a fixed `C`, call a child construction a **`C`-reset host** for
`(H_m,E_m)` when it satisfies all of the following.

1. **Exact Pascal payload.**  It uses the exact child owner and target
   multiplicities and the deadline `d'` from the scalar/four-sector
   recurrence.  Its preword has length `B_(m+1)` and rebuilding/consolidation
   leaves exactly one pivot star after insertion.
2. **Fresh pivot relay.**  It contains the child-native block of Theorem
   2.1, with incoming value `H_m+{x}` and outgoing value `H_(m+1)`.
3. **Protected topology.**  The aperture seam is the global opened seam,
   and either Proposition 4.1 or the direct ordered-Hall alternative gives
   one protected Hamilton owner path.
4. **Deck and residence.**  The complete upper interval-OR deck and all
   signed residence rows hold in the child word.  These are checked on the
   fresh child, not inferred from the discarded parent suffix.
5. **Boundary bundle.**  The occurrence-level bundle in Theorem 3.1 exists
   in the same word and common state.
6. **Common cap.**  The transported background, the pivot rays, and both
   occurrence coordinates satisfy (5.2), and their omitted set is some
   `E_(m+1)` obeying (5.3).  Every incoming ticket in `E_m` is either served
   or represented in this new bounded omitted set; no additional omitted
   tickets are carried outside `E_(m+1)`.

The last sentence is the nonaccumulation row.  Merely proving
`delta_cap<=C` on the newborn tickets while retaining all of `E_m` would
give `|E_(m+1)|<=|E_m|+C` and would not prove an additive constant.

## 7. Conditional regeneration theorem

### Theorem 7.1 (one-token regenerative overlay)

Fix `C`.  Suppose there is one accepted base state on each parity and, for
every sufficiently large `m` and every accepted state `(H_m,E_m)`, a
`C`-reset host exists.  Then the states regenerate indefinitely with

\[
                         |E_m|\le C                    \tag{7.1}
\]

and one aperture token at every stage.  At every terminal odd dimension,
appending the at most `C` omitted literal targets gives

\[
                         \nu(2m-1)\le B_m+1+C.         \tag{7.2}
\]

If `C=0`, then

\[
                         \nu(2m-1)\le B_m+1.           \tag{7.3}
\]

The analogous statement holds on the even same-parity chain once its
exact payload recurrence and the same reset-host interface are supplied.

### Proof

Apply Theorem 2.1 to the tagged incoming token.  The reset host embeds its
fresh pivot with one star, and its topology condition makes the aperture
seam the unique global opening.  The sharp pivot transports every old
interval value locally and gives the exact two-ray lower reassignment.
Theorem 3.1 identifies the pivot debt, lower-palette boundary, and diagonal
router boundary, so the one exterior bundle closes all three without a
second token.  The host's all-width and residence rows complete the literal
carrier.  Its common-cap row serves every ticket except `E_(m+1)`, whose
size is at most `C` and which, by definition of a reset host, replaces
rather than augments `E_m`.

Thus `(H_(m+1),E_(m+1))` is an accepted state of the same form.  Induction
proves (7.1).  At the requested terminal dimension, append each omitted
target as one literal source letter.  Appending cannot destroy an existing
interval witness, so the resulting word is universal and has length at
most `B_m+1+C`.  This proves (7.2)--(7.3).  \(\square\)

## 8. Minimality and exact remaining theorem

Within the one-aperture architecture, the boundary-token count one is
sharp.

* The pivot has one locally unrealized colour `J`.
* A Hamilton path has one omitted lower-`q1` colour.
* If the aperture transition is not the opened seam, these colours are
  distinct, so two boundary obligations remain.
* Opening at the aperture and using (3.4) makes them equal; the diagonal
  router adds no further logical token.

This is sharpness in named-token arity, not in bit complexity.

The exact missing all-dimensional statement is now:

> **Extension-surjective reset-host lemma.**  For every sufficiently large
> `m` and every incoming rank-`(r_m-1)` token `H_m` (or at least for every
> token in one nonterminating transition orbit), there is a fresh
> `C`-reset host for an absolute `C`.

The proved ingredients remove scalar slack, pivot geometry, local lower
compilation, one-coordinate terminal routing, and abstract component Hall
from this lemma.  Its unresolved content is correlated:

1. fresh protected upper/all-width/resident host selection;
2. prescribed-endpoint port Hall plus protected cycle absorption (or one
   direct ordered connector forest);
3. one literal boundary bundle at the opened aperture; and
4. the remaining two-coordinate/background all-cut common-cap inequality
   with nonaccumulating deficiency.

No bounded first-exit converter or fixed-fibre switch argument proves these
rows.  Proposition 4.2 and the inherited-packet residence horizon show
exactly why those two shortcuts fail.
