alternating rank-seven/rank-eight C6 through it is determined by one

\[

R_1=S_1+\{c\},\quad S_2=C+\{c\},\quad R_2=C+\{a,c\}.

of the `19448` rank-seven targets, carrying its current rank-eight receiver
root.  Add `x -> y` when `y` is a different rank-seven subset of the root

## 6. Scope correction

The SCC calculation does **not** prove that 162 socket zeros persist under
all fixed-root suffix rethreads.  Moving other H middles changes the global
long-mode catalogue and can create new predecessor/successor witnesses for
an unchanged P2 role.  Therefore the following stronger statement is not
yet justified:

> every fixed-root suffix-circuit strategy leaves 162 socketless roles.

The exact alternatives are now cleanly separated:

1. a move-each-defect architecture must recouple rank-seven targets to new
   rank-eight roots;
2. a fixed-root architecture remains possible only through regenerated
   endpoint/state DNFs that repair some immovable target occurrences
   indirectly.

The immediate fixed-root C6 module is now closed as a three-column protected
old-mode harvest.  The broader next selector should retain the protected H
bank and projection-perfect supplier row, take structural C6s only as
optional correlated three-row columns, and jointly choose the global
three-level/root assignment plus complete regenerated fixed/free
endpoint/state DNFs.  The separate `L-M-R + L-R -> M-R + L-L-R`
short-transfer family is outside the fixed rank-seven assignment SCC and is
therefore a high-priority typed catalogue.  Chronology, residence, upper
shadows, common cap/compiler feasibility, and the word remain outside this
audit.
