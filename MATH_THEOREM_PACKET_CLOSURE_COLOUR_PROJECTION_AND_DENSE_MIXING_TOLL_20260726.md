# Packet closure after quota reset: colour projection, a stable dense-mixing toll, and the exact wreath configuration

Date: 2026-07-26

Method: pure mathematics only.

## 0. Outcome

Let

\[
 \Omega=\binom{[2m]}m,\qquad W=|\Omega|.
\]

The reset-aware layered Boolean flow solves the marginal copy transport,
but it does not close the selected root paths into physical Johnson cycles.
This note proves a stable obstruction to the two proposed cheap closure
mechanisms.

1. **A bounded reset colour does not change physical closure.**  If one
   coloured path is selected over each physical owner and the coloured
   memory equations project to the ordinary memory equations, then
   forgetting the colour again gives one physical owner permutation.
   Hence every power, run, and permutation-square obstruction survives.
   To evade it by colours one must use more than one physical occurrence
   of some owner, which violates owner-disjointness.

2. **Sparse component mixing is impossible.**  There is a canonical
   partition of all but

   \[
                             E_m\le 4\,10^{\lfloor m/2\rfloor} \tag{0.1}
   \]

   owners into six-element physical fibres, each an induced
   \(J(4,2)\).  Since

   \[
                         {E_m\over W}
        =O\!\left(\sqrt m\left({\sqrt{10}\over4}\right)^m\right)=o(1),
                                                                    \tag{0.2}
   \]

   these fibres cover \((1-o(1))W\) owners.

   If a partial \(2\)-safe owner permutation covers \(W-L\) owners and
   \(M\) of its selected transitions leave their canonical six-fibre,
   then

   \[
                  \boxed{M\ge {W-E_m\over6}-L.}                  \tag{0.3}
   \]

   In particular, when \(L=o(W)\), one has
   \(M\ge(1/6-o(1))W\).  Since every \(H\)-safe factor with \(H\ge2\) is
   \(2\)-safe, (0.3) applies throughout the protected window.  Thus an
   owner factor made by joining locally closed reset components with only
   \(o(W)\) physical seams cannot exist.

The obstruction is stable but not global.  Two adjacent six-fibres can
be mixed into an explicit physical \(2\)-safe \(12\)-cycle.  The lesson is
that the square obstruction is removed by **dense physical mixing**, not
by a finite label and not by sparse seam repair.

For completeness, the note also gives the exact all-depth configuration
which dense mixing would have to integralize.  Take all length-\(2m\)
wreath cycles and contract complementary owners.  For every signed target
at depth \(q\), create \(c_q\) compulsory clones and one optional clone,
where

\[
 {W\over N_q}=c_q+\alpha_q,qquad
 N_q=\binom{2m}{m-q}.                                         \tag{0.4}
\]

Lift a wreath cycle by assigning each of its target occurrences to one
of the corresponding clones.  This lifted hypergraph has an exact
fractional matching with:

\[
 \deg_f(p)=1\quad\hbox{for every complementary owner pair }p,  \tag{0.5}
\]

\[
 \deg_f(T,i)=1\quad(1\le i\le c_q),\qquad
 \deg_f(T,*)=\alpha_q.                                        \tag{0.6}
\]

An integral matching covering all but \(o(W)\) compulsory vertices would
give an owner-disjoint \(H\)-safe factor with aggregate target error
\(o(W)\), and it would use at most

\[
                             {W\over2m}=o(W/H)                   \tag{0.7}
\]

cycles whenever \(H=o(m)\).  Thus quota reset and every fractional cut
are already incorporated in one exact configuration.  What remains is an
integral growing-rank hypergraph matching theorem for that configuration.
The dense-mixing toll (0.3) proves that it cannot be obtained by a bounded
colour lift or by \(o(W)\) component splices.

No asymptotic impossibility of the unrestricted dense configuration is
claimed.

## 1. Bounded colours project to the same physical permutation

Let \(K\) be a finite colour set, allowed to depend on neither the owner
nor the time along a selected window.  A coloured safe window is

\[
 \widehat\gamma=\bigl((X_0,k_0),(X_1,k_1),\ldots,(X_H,k_H)\bigr),
                                                                    \tag{1.1}
\]

whose physical projection \((X_0,\ldots,X_H)\) is an \(H\)-safe Johnson
path.  Suppose exactly one coloured window is selected over each physical
root \(X\), and suppose coloured prefix--suffix conservation implies the
ordinary physical prefix--suffix conservation after colours are summed.

### Theorem 1.1 (colour projection rigidity)

The physical projection of every such integral coloured circulation is
generated by one permutation \(P\) of \(\Omega\).  Its selected window at
\(X\) is

\[
                         (X,PX,P^2X,\ldots,P^HX).                \tag{1.2}
\]

In particular, a bounded colour cannot change any obstruction expressed
solely in the physical powers of \(P\).

#### Proof

Sum the selected coloured variables over every colour fibre.  The root
row becomes one selected physical window over every owner, and the memory
rows become ordinary prefix--suffix conservation.  The first physical
edge defines \(P(X)=X_1\).  The suffix of the selected window at \(X\)
must equal the prefix selected at \(PX\); hence its next vertex is
\(P^2X\).  Induction proves (1.2).  Physical indegree equals physical
outdegree one, so \(P\) is a permutation. \(\square\)

The theorem does not use \(|K|\).  Even an unbounded colour alphabet is
irrelevant if precisely one coloured copy is selected over every physical
owner.  A colour lift can alter the square obstruction only by retaining
two or more coloured copies over some physical owner, or by dropping a
physical memory equation.  Neither operation is an owner-disjoint Johnson
cycle factor.

## 2. Canonical first-eligible \(J(4,2)\) fibres

Partition \([2m]\) into

\[
                         b=\lfloor m/2\rfloor                  \tag{2.1}
\]

ordered four-blocks \(B_1,\ldots,B_b\), together with a residual block
\(R\) of size \(r=2m-4b\in\{0,2\}\).  Call an owner \(X\) *good* if
\(|X\cap B_j|=2\) for at least one \(j\), and let \(j(X)\) be the first
such index.

For a good owner put

\[
 \mathcal F(X)={(X\setminus B_{j(X)})\cup S:
                         S\in\tbinom{B_{j(X)}}2\}.              \tag{2.2}
\]

### Lemma 2.1 (six-fibre partition)

The sets \(\mathcal F(X)\) form a partition of all good owners into
six-element induced copies of \(J(4,2)\).

#### Proof

Varying the two-subset inside \(B_{j(X)}\) changes neither an earlier
block rank nor the fact that block \(j(X)\) has rank two.  Thus all six
members of (2.2) have the same first eligible block and the same exterior.
Consequently they define the same fibre.  Two fibres which meet therefore
have the same first block and exterior and are equal.  Johnson adjacency
inside a fibre is exactly adjacency of two-subsets of its four-block.
\(\square\)

### Lemma 2.2 (exponentially small exceptional set)

The number \(E_m\) of bad owners satisfies (0.1)--(0.2).

#### Proof

On a four-block, the allowed local ranks for a bad owner are
\(0,1,3,4\), with enumerator

\[
                         p(x)=1+4x+4x^3+x^4.                    \tag{2.3}
\]

Therefore

\[
 E_m=[x^m]p(x)^b(1+x)^r
 \le p(1)^b2^r=10^b2^r\le4\,10^b.                            \tag{2.4}
\]

The elementary central-binomial lower bound
\(W\ge4^m/(2\sqrt m)\) now gives (0.2), after changing the absolute
constant for odd \(m\). \(\square\)

## 3. The stable dense-mixing toll

Let \(\Omega'\subseteq\Omega\), \(|\Omega'|=W-L\), and let
\(P\) be a permutation of \(\Omega'\) whose transitions are Johnson edges
and whose cyclic two-step windows are geodesic.  Call a selected tail
\(X\in\Omega'\) *crossing* if \(X\) is bad or if
\(P(X)\notin\mathcal F(X)\).  Let \(M\) be the number of crossing good
tails; bad tails may be charged separately to the exponentially small
\(E_m\).

### Theorem 3.1 (one physical crossing per intact six-fibre)

The number of crossing good tails satisfies

\[
                         M\ge {W-E_m\over6}-L.                  \tag{3.1}
\]

#### Proof

There are \((W-E_m)/6\) good fibres.  At most \(L\) of them fail to be
entirely contained in \(\Omega'\), because every non-full fibre contains
at least one omitted owner.

Consider a full good fibre \(\mathcal F\) with no crossing tail.  Then
\(P(\mathcal F)\subseteq\mathcal F\).  Since \(P\) is injective and
\(|\mathcal F|=6\), its restriction is a permutation of \(\mathcal F\).
Write the fibre as

\[
                         \{C\cup S:S\in\tbinom B2\},            \tag{3.2}
\]

where \(|B|=4\) and \(C\cap B=\varnothing\).  Two-step safety gives

\[
                         d_J(C\cup S,P^2(C\cup S))=2.           \tag{3.3}
\]

Inside this fibre the unique vertex at Johnson distance two from
\(C\cup S\) is \(C\cup(B\setminus S)\).  Hence

\[
                         P^2(C\cup S)=C\cup(B\setminus S)       \tag{3.4}
\]

for all six vertices.  But complementation on \(\binom B2\) is a product
of three transpositions.  A permutation square contains transpositions in
pairs, one pair from each four-cycle, so it cannot equal (3.4).  This is a
contradiction.

Thus every full good fibre supplies at least one distinct crossing tail.
There are at least \((W-E_m)/6-L\) such fibres, proving (3.1).
\(\square\)

### Corollary 3.2 (no sparse packet closure)

Let \(H\ge2\).  Any \(H\)-safe partial factor covering \(W-o(W)\) owners
uses at least

\[
                            (1/6-o(1))W                         \tag{3.5}
\]

transitions between the canonical six-fibres.  Consequently:

1. bounded reset colours cannot close the fibres;
2. changing only \(o(W)\) successor edges of a fibrewise factor cannot
   make it \(H\)-safe; and
3. a packet construction whose physical axes cross these fibres on only
   \(o(W)\) selected tails cannot yield the desired factor.

This is stable under an \(o(W)\) owner leave.  It is not an entropy
argument and it is independent of target quotas.

## 4. Dense mixing really removes the local square obstruction

The lower bound (3.1) does not say that closure is impossible.  Here is a
literal two-fibre escape.

Let \(B=\{1,2,3,4\}\), let \(C,D\subseteq[2m]\setminus B\) have size
\(m-2\), and suppose

\[
                         C=K\cup\{x\},\qquad D=K\cup\{y\}       \tag{4.1}
\]

for distinct \(x,y\notin B\).  Thus the two fibres
\(\{C\cup S:|S|=2\}\) and \(\{D\cup S:|S|=2\}\) are joined by the six
vertical Johnson edges which exchange \(x\) and \(y\).

Choose the cyclic Hamilton order

\[
 12,13,34,14,24,23                                             \tag{4.2}
\]

of \(J(4,2)\).  If these sets are \(S_0,\ldots,S_5\), then

\[
\begin{aligned}
 C\cup S_0,&\ D\cup S_0,\ D\cup S_1,\ C\cup S_1,\
 C\cup S_2,\ D\cup S_2,\\
 D\cup S_3,&\ C\cup S_3,\ C\cup S_4,\ D\cup S_4,\
 D\cup S_5,\ C\cup S_5
\end{aligned}                                                   \tag{4.3}
\]

is a cyclic Johnson \(12\)-cycle.

### Lemma 4.1 (two-fibre physical escape)

Every two consecutive transitions in (4.3) are geodesic.

#### Proof

The transitions alternate between a vertical exchange of \(x,y\) and an
internal exchange using only coordinates of \(B\), including at the cyclic
seam.  Consecutive transitions therefore use disjoint coordinate pairs.
Their two-step path is a Johnson geodesic. \(\square\)

Thus physical component mixing, unlike colour augmentation, genuinely
removes the local permutation-square obstruction.  It uses six crossing
tails on two fibres, so it is a dense rather than a sparse repair.  The
cycle (4.3) is only a closure certificate; it asserts no target balance
and no safety beyond depth two.

## 5. The exact dense all-depth configuration

The natural dense candidates are wreath cycles.  A cyclic order

\[
                         \pi=(v_0,v_1,\ldots,v_{2m-1})           \tag{5.1}
\]

gives the cycle

\[
                         X_i=\{v_i,v_{i+1},\ldots,v_{i+m-1}\},
                         \qquad i\in\mathbb Z_{2m}.             \tag{5.2}
\]

Every segment of at most \(m\) transitions is geodesic.  The cycle
contains both \(X_i\) and \(X_i^c=X_{i+m}\); after complementary owners
are contracted, it is an \(m\)-set of owner-pair vertices.

For \(q<m\), its signed targets are

\[
 L_q(i)=\{v_{i+q},\ldots,v_{i+m-1}\},\qquad
 U_q(i)=\{v_i,\ldots,v_{i+m+q-1}\}.                             \tag{5.3}
\]

For each fixed \(q\) and sign, the \(2m\) targets in (5.3) are distinct.

Let \(\mathscr W\) be the hypergraph whose vertices are complementary
owner pairs and whose edges are the wreath cycles.  Coordinate symmetry
makes it regular.  Give every edge the reciprocal of the common owner-pair
degree.  This is a fractional perfect matching \(w\), and

\[
                         \sum_{C\in\mathscr W}w_C={W\over2m}.   \tag{5.4}
\]

At every signed depth \(q\), symmetry and (5.3) give every physical target
the fractional load

\[
                         \lambda_q={W\over N_q}.                 \tag{5.5}
\]

### 5.1 Quota clones

For every signed target \(T\) at depth \(q\), create the slots

\[
                         (T,1),\ldots,(T,c_q),(T,*).             \tag{5.6}
\]

The first \(c_q\) slots are compulsory and \((T,*)\) is optional.  A
*lift* of a physical wreath cycle assigns each occurrence (5.3) to one of
the slots belonging to its target.  Since the targets of one sign and
depth are distinct on a wreath cycle, no local injectivity problem occurs.

Let \(\widehat{\mathscr W}_H\) be the hypergraph whose vertices are:

1. the complementary owner pairs; and
2. all slots (5.6), for both signs and every \(q\le H\).

A lifted edge contains its \(m\) owner-pair vertices and one slot for each
of its \(4mH\) signed target occurrences.  Hence it has rank

\[
                              m(4H+1).                           \tag{5.7}
\]

### Theorem 5.1 (exact reset-aware fractional packet closure)

The lifted wreath hypergraph has a fractional matching \(\widehat w\)
for which every owner-pair vertex and every compulsory target slot has
degree one, while every optional slot at depth \(q\) has degree
\(\alpha_q\).

#### Proof

Start with the symmetric physical weight \(w_C\).  Independently for each
target occurrence at depth \(q\), assign it to a specified base slot with
probability

\[
                              {1\over\lambda_q},                 \tag{5.8}
\]

and to the optional slot with probability

\[
                              {\alpha_q\over\lambda_q}.         \tag{5.9}
\]

These probabilities sum to one because
\(c_q+\alpha_q=\lambda_q\).  Give a lifted cycle its physical weight
times the product of its assignment probabilities.

Summing over lifts restores \(w_C\), so every owner-pair degree remains
one.  A physical target has load \(\lambda_q\) by (5.5).  Multiplying by
(5.8) gives degree one for each of its \(c_q\) base slots; multiplying by
(5.9) gives degree \(\alpha_q\) for its optional slot.  Since all vertex
degrees are at most one, this is a fractional matching. \(\square\)

This incorporates every quota reset automatically.  No high family is
chosen in advance: the optional slots selected by an integral matching
become the high family.

### Theorem 5.2 (the exact remaining integral statement)

Suppose \(\widehat{\mathscr W}_H\) has an integral matching \(\mathcal M\)
which leaves altogether \(o(W)\):

1. complementary owner-pair vertices; and
2. compulsory target slots, summed over both signs and all \(q\le H\).

Then the physical wreath cycles underlying \(\mathcal M\) form an
owner-disjoint \(H\)-safe partial cycle factor with owner leave \(o(W)\),
aggregate signed target error \(o(W)\), and at most \(W/(2m)=o(W/H)\)
cycles for \(H=o(m)\).

#### Proof

Matching on owner-pair vertices makes the physical wreath cycles
owner-disjoint.  If \(s\) owner-pair vertices are uncovered, the physical
owner leave is \(2s=o(W)\).  Every selected cycle is \(H\)-safe by (5.2).

At a target \(T\), matching of the clone vertices gives physical load at
most \(c_q+1\).  If an optional clone is used while a base clone of the
same target is unused, relabel that occurrence to the unused base clone.
After these harmless relabellings, every deficit below \(c_q\) is exactly
an uncovered compulsory clone.  Their aggregate number is \(o(W)\).

Every selected wreath cycle uses \(m\) owner-pair vertices, so the number
of cycles is at most \((W/2)/m=W/(2m)\).  When \(H=o(m)\), this is
\(o(W/H)\). \(\square\)

## 6. Exact verdict

The \(m=H=2\) square obstruction cannot be circumvented by adding a
bounded reset colour while retaining one physical occurrence per owner.
The obstruction can be circumvented by physical component mixing, but
Theorem 3.1 proves that any asymptotically spanning safe factor must mix
the canonical local components on \(\Omega(W)\) selected transitions.
Thus a sparse seam or post-processing repair is ruled out stably.

At the same time, Theorem 5.1 shows that dense wreath mixing has no
fractional quota, reset, owner, or all-depth target obstruction.  The
coefficient-one packet-closure problem is reduced to the single integral
matching assertion in Theorem 5.2 for the growing-rank hypergraph
\(\widehat{\mathscr W}_H\).  Proving a generic nibble estimate is not
enough: its leave must be \(o(W)\) in absolute total over \(2H\) target
parts, rather than merely an \(o(1)\) fraction of their
\(\Theta(WH)\) vertices.

This is the exact boundary established here:

\[
\boxed{
 \text{bounded colours and sparse mixing fail stably;}
 \quad
 \text{dense clone-aware wreath matching remains the sole gate.}}
\]
