## 1. Why the old gate is retired

The earlier component-permutation census scored only the fixed `exact_229`
212-left/187-right Hall shore.  That score is not stable under source-row
losses.  The materialized leaf for collar 5960 reached restricted matching
`211/212`, yet independent exact replay found 18 arbitrary-upper holes and
complete generalized Hall matching only

```text

```

Thus a positive gain against the fixed shore is not a valid production
certificate for a changed chronology.  The stopped raw prefix remains useful
only as a structural-search timing diagnostic.

## 3. Exact gate order

Every signed-component structural leaf is processed in this order:

1. exact streaming and independent batch carrier replay;
2. exact U20 signature matching, required value `20/20`;
3. arbitrary-upper contiguous-OR replay, required hole count zero;
4. complete proper-prefix incidence graph for all 26,332 rank-below-eight
   masks and exact Hopcroft--Karp matching, required value `26332/26332`.

The complete graph is generated by enumerating allowed submasks of each
physical cell and applying the exact mandatory-mask and per-envelope-letter
tests.  The engine records incidence count, matching deficiency, and the
left/right sizes of a canonical alternating Hall witness.  Every
upper-complete leaf is materialized for independent replay, including a leaf
that fails the final Hall gate.  Only a full-Hall pass is compiler-eligible.

## 6. Scope

This gate applies only to the authenticated `rank1_j3959` source, the 57,216
loss-robust contextual collars, and the engine's frozen signed permutation of
maximal occurrence-labelled residual components with unchanged values and

census can prove only a no-go or yield a survivor inside that fixed class.
