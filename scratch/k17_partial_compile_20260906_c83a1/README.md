# Isolated Partial Compiler

Sources: `scripts/k17_partial_compile_20260906_c83a1.{cpp,py}`.

The compiler deliberately permits an exact maximum matching to be deficient.
It preserves `DA = DP` on each literal physical cycle, opens each cycle with
three prefix letters, and computes the complete nonwrapping missing census.
No arbitrary-width closure lemma is assumed. Every retained final word is
repaired explicitly and checked by suffix-OR counts and an independent
next-occurrence event scan. Exact compression is restricted to the appended
repair region, using the unchanged `a19f7` edit engine.

This directory is reserved for factor snapshots, candidate bodies, commands,
hashes, exact missing ledgers, and the bounded h100 run reports. A universal
word of length at least 25745 is diagnostic, not an improvement.
