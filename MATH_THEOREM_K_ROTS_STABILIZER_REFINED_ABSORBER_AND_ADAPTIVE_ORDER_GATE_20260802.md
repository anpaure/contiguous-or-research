# ROTS stabilizer refinement, cut-safe absorbers, and the adaptive-order gate

**Date:** 2026-08-02  
**Status:** exact rooted-static extension theorem and exact chronology
obstruction.  The theorem does not construct the required large reset bank
and does not prove the decorated integral common-base row.  Residence, upper
decks, topology, common-cap, compiler, and words are outside scope.

## 0. Main result

Let \(G_\tau=(L,R;E_\tau)\) be the literal product-order successor graph of a
fixed-core chronology \(\tau\).  A protected internally valid socket bank
uses a literal partial matching \(P\subseteq E_\tau\).  Refining the core
action by every named set of \(P\) converts the asymmetric rooted extension
problem back into one exact finite type flow.

This gives three sharp conclusions.

1. A bounded literal protected bank has an exact polynomial rooted-extension
   test after stabilizer refinement.
2. Protected socket charge is nonnegative on every Hall cut.  Sockets cannot
   repair a chronology which was already statically deficient.
3. Therefore the K17 and K21 deterministic next-fit chronologies require
   genuine reordering which exposes at least \(286\) and \(9\,504\) new right
   units, respectively.  Merely splitting their orbit types while inheriting
   the same times cannot work.

## 1. Stabilizer-refined rooted extension

Let \(H\) be the pointwise fixed core.  Let \(\mathcal S(P)\) contain every
literal set whose identity or membership is named by the protected bank:
the used left and right endpoints and every endpoint/history set appearing
in its admissibility predicate.

Outside \(H\), let \(\mathcal A(P)\) be the Boolean algebra generated by
\(\mathcal S(P)\), and let \(\Gamma_P\) be the product of the symmetric groups
on its coordinate atoms.  Every member of \(\mathcal S(P)\) is a union of
atoms and hence is fixed setwise by \(\Gamma_P\).  In particular every
endpoint used by \(P\) is a singleton \(\Gamma_P\)-orbit.

Assume a chronology \(\tau'\) is constant on \(\Gamma_P\)-orbits.  Partition
the residual left and right vertices into the resulting types
\(L_i^P,R_j^P\).  Every nonempty residual relation
\[
 E_{ij}^P=E_{\tau'}[L_i^P,R_j^P]                     \tag{1.1}
\]
is invariant under a group transitive on both shores, and is therefore
biregular.

### Theorem 1.1 (stabilizer-refined protected extension)

Let \(f_{ij}\) count the prescribed edges of \(P\) from refined type \(i\)
to refined type \(j\).  The following are equivalent.

1. \(P\) extends to a matching saturating every left target.
2. The refined type network has a flow \(F\) satisfying
   \[
   \sum_jF_{ij}=s_i,\qquad
   \sum_iF_{ij}\leq c_j,\qquad
   F_{ij}\geq f_{ij},                                \tag{1.2}
   \]
   where \(s_i=|L_i|\), \(c_j=|R_j|\).
3. After putting
   \[
   p_i=\sum_jf_{ij},\qquad q_j=\sum_if_{ij},          \tag{1.3}
   \]
   every refined type cut obeys
   \[
   \boxed{
   q(N(X))-p(X)\leq
   \sigma_{\tau'}(X):=c(N(X))-s(X).}                 \tag{1.4}
   \]

#### Proof

Subtract the protected partial matching.  The residual problem is to
saturate \(L\setminus V_L(P)\) inside
\[
 G_{\tau'}[(L\setminus V_L(P)),(R\setminus V_R(P))]. \tag{1.5}
\]
Its residual type supplies and capacities are \(s_i-p_i\) and \(c_j-q_j\).
Every residual pair graph is biregular.  A feasible residual type flow may
therefore be spread uniformly on each pair graph, producing a fractional
literal matching which saturates every residual left vertex and has right
load at most one.  Bipartite matching integrality produces a literal
completion.  The reverse implication follows by aggregation.  Max-flow /
min-cut gives (1.4), and adding back \(f\) gives (1.2). \(\square\)

The theorem is an exact rooted extension result, not a fractional heuristic.
It applies to a full developed bank, a subgroup-developed bank after orbit
refinement, or a bounded literal collar.  It does not say that an arbitrary
large bank has bounded state.

## 2. Refinement complexity and its sharp limit

Suppose \(r\) named sets generate \(a\) outside-core atoms.  Then
\[
                         a\leq2^r.                   \tag{2.1}
\]
An orbit is determined by its fixed-core pattern and the number of selected
coordinates in every atom.  Hence the number of static refined types is at
most
\[
                         2^{|H|}(k+1)^a
                         \leq2^{|H|}(k+1)^{2^r}.      \tag{2.2}
\]
For bounded \(r\), this is polynomial and gives an exact finite
rooted-extension test.

The exponent cannot be improved for arbitrary named sets by another
stabilizer argument.  If all \(2^r\) membership patterns are nonempty, every
permutation preserving the \(r\) named sets must preserve each membership
cell.  Thus it has at least \(2^r\) coordinate orbits.

Consequently an \(O(d)\)-socket bank is not automatically a bounded-state
interface.  A uniform theorem must use a subgroup-developed template or a
bounded marker algebra shared by all sockets.

## 3. Protected charge cannot repair an old Hall deficit

For a left-type set \(X\), define the protected cut charge
\[
                         \chi_P(X)=q(N(X))-p(X).      \tag{3.1}
\]
Here \(N(X)\) is taken in the full refined graph; protected singleton right
types are retained with residual capacity zero.  Equivalently, one may work
directly with the same literal left set before and after deletion.

### Lemma 3.1 (nonnegative protected charge)

For every \(X\),
\[
                         \boxed{\chi_P(X)\geq0}.       \tag{3.2}
\]

#### Proof

Every protected left endpoint lying in \(X\) is mapped by the matching \(P\)
to a distinct protected right endpoint in \(N(X)\).  Hence
\(q(N(X))\geq p(X)\). \(\square\)

### Corollary 3.2 (mandatory new neighborhood capacity)

If \(X\) is a Hall witness for \(\tau\) with deficit
\[
       \delta=s(X)-c(N_\tau(X))>0,                   \tag{3.3}
\]
then every reordered chronology \(\tau'\) and protected bank \(P\) which
passes (1.4) satisfy
\[
 \boxed{
 c(N_{\tau'}(X))-c(N_\tau(X))
 \geq \delta+\chi_{P,\tau'}(X)\geq\delta.}           \tag{3.4}
\]

Thus a protected bank never repairs an already deficient chronology by
itself.  Orbit splitting which inherits every old time leaves the literal
neighborhood \(N_\tau(X)\) unchanged and cannot help.

For the frozen deterministic logarithmic-core next-fit chronology, (3.4)
requires at least
\[
 286\quad\text{new right units at K17},\qquad
 9\,504\quad\text{new right units at K21}.            \tag{3.5}
\]
This is a lower bound on reordering gain, not on socket count.
The comparison uses the same literal left set \(X\) in both chronologies.
If a quotient split separates \(X\), its refined pieces must first be pulled
back to that literal shore.

## 4. Two exact absorber criteria

### Theorem 4.1 (tight-cut absorber)

Assume \(G_\tau\) already has a left-saturating matching and define
\[
 \mu=\min\{\sigma_\tau(X):\sigma_\tau(X)>0\},         \tag{4.1}
\]
with \(\mu=\infty\) when there is no positive cut slack.  If
\[
 \chi_P(X)=0\quad\text{on every tight cut},\qquad
 |P|\leq\mu,                                         \tag{4.2}
\]
then \(P\) extends.

#### Proof

On a tight cut, (1.4) is exactly the first condition in (4.2).  On every
other cut,
\[
              \chi_P(X)\leq |P|\leq\mu\leq\sigma_\tau(X). \tag{4.3}
\]
Theorem 1.1 applies. \(\square\)

For a single protected edge \(i\to j\), the tight-cut condition is exact:
every tight \(X\) with \(j\in N(X)\) must contain \(i\).  This is precisely
the Dulmage--Mendelsohn allowed-edge criterion.  A multi-edge bank extends
sequentially exactly when its edges can be deleted in some order while each
is allowed in the current residual graph.

The cut-charge form is evaluated in the full literal graph, or in a refined
type graph retaining protected singleton types with zero residual capacity.
A quotient which merges protected and unprotected vertices does not satisfy
the theorem's hypotheses.

### Theorem 4.2 (explicit reserve absorber)

Let \(M\) saturate \(L\), let
\[
 A=\{\ell\in L\setminus L_P:M(\ell)\in R_P\},         \tag{4.4}
\]
and let
\[
 Z\subseteq R\setminus(M(L)\cup R_P)                 \tag{4.5}
\]
be unused right reserve.  If \(G[A,Z]\) has a matching saturating \(A\),
then \(P\) extends.

#### Proof

Retain \(M\) off \(L_P\cup A\), use \(P\) on \(L_P\), and use the
\(A\)-to-\(Z\) matching on \(A\).  The three right images are pairwise
disjoint by (4.5), and every left vertex is covered. \(\square\)

This is the occurrence-level absorber to seek in the K19/K21 owner reserve.
It requires an actual matching in \(G[A,Z]\), not merely
\(|A|\leq|Z|\), and requires no uniform orbit deletion.  Longer
vertex-disjoint alternating paths to reserve give a more general variant;
Theorem 4.2 is the direct-edge special case.

## 5. Adaptive chronology is load-bearing

For a fixed chronology, Theorem 1.1 is a max-flow.  When the chronology is
also selected, put every refined type into one capacity-\(W\) time block and
permit successor flow only to a later compatible block.  The chronology
variables, type flow, address flags, and reset sockets must be chosen jointly.

The deterministic next-fit failures prove that arbitrary order is false.
Theorem 3.2 proves more: refinement without time reassignment is also false.
A successful adaptive splitter must explicitly expose the new capacity in
(3.4), while its protected bank remains neutral on inherited tight cuts or
is absorbed by Theorem 4.2.

This isolates a proof-grade sufficient target.

### Adaptive bounded-marker ROTS absorber

Choose a bounded marker algebra and a chronology on its refined orbits such
that:

1. the protected reset bank is a literal partial matching generated by that
   algebra;
2. every old deficient shore gains at least its deficit in new later
   compatible right capacity;
3. the protected bank is neutral on all new tight cuts and has size at most
   the minimum positive slack, or has an explicit reserve matching;
4. the flag endpoint types satisfy the exact three-threshold reset equations;
5. the long/short block count obeys
   \(\rho(D)\leq b\leq N_{\rm short}\).

Under these hypotheses, Theorems 1.1 and 4.1/4.2 close the rooted **static**
factor extension.  The decorated row/transition exact cover remains a
separate integral common-base problem; the known three-resource parity
tensor shows that fractional orbit feasibility alone does not close it.

### Theorem 5.1 (exact decomposition and first non-TU row)

After the chronology, protected bank, and refined stabilizer are fixed:

1. the residual static extension is a bipartite max-flow and is totally
   unimodular;
2. the three-threshold reset assignment is an interval transportation flow
   and is totally unimodular; but
3. the common selector tying target-chain/owner choice to incoming,
   outgoing, and socket state is not totally unimodular in general.

The third row contains the three-resource even-parity tensor as a
determinant-two minor.

#### Proof

The node-arc incidence matrix of a bipartite flow network is totally
unimodular, proving item 1.  Reset columns are intervals of the three-edge
flag path; their consecutive-ones matrix, together with endpoint
transportation rows, is totally unimodular, proving item 2.  The four
configurations
\[
 (a_1,b_1,c_1),\ (a_1,b_2,c_2),\
 (a_2,b_1,c_2),\ (a_2,b_2,c_1)                     \tag{5.1}
\]
have the invariant half-integral solution and no integral two-row exact
cover.  The corresponding incidence minor has determinant two, proving
item 3. \(\square\)

Consequently the exact architecture is an integer master for chronology and
common literal row configurations, with the refined residual flow as a
min-cut subproblem.  Every failed subproblem returns the exact Benders cut
\[
             q(N(X))-p(X)\leq\sigma_\tau(X).          \tag{5.2}
\]
Chronology activation inside a single linear relaxation is disjunctive and
does not inherit the subproblem's integrality.

## 6. Exact K17 finite calibration

The best independently replayed recoupled K17 table currently has chain
lengths
\[
                         (n_1,n_2,n_3)=(0,7395,16915), \tag{6.1}
\]
which is the exact minimum possible number \(16915\) of long rows.  Its
complete nested-address union projection into \(16898\) hard long heads has
matching
\[
                         16809/16898,                 \tag{6.2}
\]
deficiency \(89\), \(77\) zero heads, and Hall shore \(102\) heads versus
\(13\) neighbors.  The alternate owner phase has deficiency \(164\).

A new single-core CEGAR probe used those 102 Hall heads as donor priorities.
The exact containment matching selected
\[
                         0/102                        \tag{6.3}
\]
of them: none can be shortened by the current singleton-to-donor operation.
The resulting exact-minlong table has projection matching
\[
                         16723/16898,                 \tag{6.4}
\]
deficiency \(175\) and \(152\) zero heads, so it does not supersede (6.2).

Equation (6.3) closes only the direct rule “remove the current Hall heads as
donors.”  Other recouplings may still create new suppliers for those heads.
The proof-safe next finite model is the one-short typed reset projection
\(\operatorname{1S\!-\!ROTS}(17)\): choose the global singleton-to-donor
recoupling, one address state per role, exact long arcs, and common-literal
state hyperarcs
\[
                    \text{long}\to\text{short}\to\text{long}. \tag{6.5}
\]
Every short role is used once and the selected long roles have indegree and
outdegree one.  The flag balance then enforces the reset ledger rather than
checking it marginally.

This model is still a finite projection.  SAT requires literal cyclic-cell
replay.  Builder-phase UNSAT would not close the alternate owner phase, and
fixed-table UNSAT would not close all \(401\,754\) recouplings unless the
master actually contains those choices.

## 7. Exact remaining scope

This note closes:

* rooted static extension after bounded stabilizer refinement;
* the exact tight-cut and reserve absorber criteria;
* the proof that old Hall deficiency forces real chronological reordering;
* the bounded-marker versus arbitrary-literal state distinction.

It does not construct the adaptive bounded-marker bank.  It does not prove
integral decorated-row rounding, residence, any upper deck, connected
topology, common-cap, compiler closure, or a word.
