# Selector fibres: exact nested-flag marginals and the integral grouping obstruction

Date: 2026-07-26

Method: pure mathematics only. No computation, solver, or web input is
used.

## 0. Outcome

Let a large product status cell be \(Q_S\).  Freeze a selector coordinate
set \(B\), \(|B|=t\), and put

\[
                         V=S-t.
\]

For every selector word \(z\in Q_B\), choose an active payload set
\(A_z\subseteq[V]\), \(|A_z|=r\), and an affine conjugate of the
simultaneous cube compiler.  The resulting selector-fibre construction
is an exact owner tiling.  This owner statement is correct.

The full symmetric label catalogue has exact nested marginals.  If
\((V)_q=V(V-1)\cdots(V-q+1)\), then for every payload owner \(v\) and
every ordered \(q\)-tuple \(\delta\) of distinct payload axes,

\[
 \boxed{
 \Pr\{\text{the compiler prefix at }v\text{ is }\delta\}
 ={1\over(V)_q}.}                                     \tag{0.1}
\]

Equivalently, for every fixed affine \(q\)-face \(R\subseteq Q_V\),

\[
 \boxed{
 \Pr\{R\text{ is a selected trace face}\}
 =p_{V,q}:={2^q\over\binom Vq}.}                      \tag{0.2}
\]

The same label supplies the whole nested tower, so (0.1) is a joint
prefix law, not a collection of independently chosen depthwise
marginals.  Lower and upper physical traces have the same face marginal
and occur as a coupled pair.

These identities do not derandomize physical target coverage.  The
selector axes never become active.  Hence a physical lower or upper
target retains one endpoint on every selector pair and therefore
determines its selector word \(z\) uniquely.  For a deterministic
labeling \(\lambda_z\), its occurrence inside this \(Q_S\) cell is

\[
 \boxed{
 m_q(z,R)=
 {\bf1}_{\{R\in{\cal F}_q(\lambda_z)\}}\in\{0,1\}.}   \tag{0.3}
\]

An orthogonal array may balance

\[
 \sum_z{\bf1}_{\{R\in{\cal F}_q(\lambda_z)\}},
\]

but the summands refer to the different physical targets
\((z,R)\).  They are not multiple chances for one target.  Thus an OA
inside one cell balances target cylinders; it does not remove their
holes.

There are two further exact integral obstructions.

1. To realize a prescribed abstract nested flag table, every flag in one
   selector fibre must use one common \(r\)-set:
   \[
   \boxed{
   \left|\bigcup_{v\in Q_V}D_H(z,v)\right|\le r.}      \tag{0.4}
   \]
   A balanced table which uses every payload direction inside every
   selector fibre violates (0.4) whenever \(r<V\).  Balance must be
   segregated across selector words.
2. The label-to-marginal matrix is not a network or totally unimodular
   matrix.  Already its depth-one active-set projection contains the
   determinant-two triangle
   \[
   \begin{pmatrix}
   1&1&0\\
   1&0&1\\
   0&1&1
   \end{pmatrix}.                                     \tag{0.5}
   \]

Therefore the selector construction proves a large exact integral option
space and an exact symmetric fractional point, but not an integral
balanced nested labeling.  The remaining problem is a global
cell--fibre--target grouped covering problem.  It must coordinate the one
relevant selector row from every candidate cell of the same physical
target; uniform randomness or an OA internal to each cell is
insufficient.

## 1. Exact owner tiling and label space

Identify \(Q_S=Q_B\times Q_V\).  Given \(z\in Q_B\), an active set
\(A_z\subseteq[V]\), and

\[
                         y\in Q_{[V]\setminus A_z},
\]

put

\[
 P_{z,y}
 =\{(z,v):v|_{[V]\setminus A_z}=y\}.                  \tag{1.1}
\]

For fixed \(z\), these are parallel \(Q_r\)'s partitioning the selector
fibre.  Different \(z\)'s are disjoint.  Hence (1.1) partitions \(Q_S\)
for arbitrary choices of \(A_z\).

Let \(F_r\) be one compiler factor with simultaneous injective traces
through depth \(H\).  A label is

\[
                         \lambda=(A,g),
\]

where \(A\in\binom{[V]}r\) and \(g\) is generated by an axis permutation
and endpoint reversals of \(Q_A\).  The full indexed label catalogue has
size

\[
 |{\cal L}|=\binom Vr\,2^rr!=2^r(V)_r.                \tag{1.2}
\]

Some labels may define the same physical factor because of stabilizers;
keeping indexed labels is harmless for the fractional count.  Integral
coverage must eventually quotient physically identical options.

The budget

\[
 t\ge\left\lceil\log_2|{\cal L}|\right\rceil
 =r\log_2(V/r)+r\log_2r+O(r)                          \tag{1.3}
\]

is \(o(S)\) for the proposed sublinear packet dimensions.  It supplies
enough selector words to list every indexed label at least once.  It does
not make the number \(2^t\) divisible by \(|{\cal L}|\), nor does it
provide many complete repetitions.

## 2. Pointed nested-prefix marginal

Fix \(v\in Q_V\) and an ordered tuple

\[
                         \delta=(i_1,\ldots,i_q)
\]

of distinct payload axes.  Choose \(\lambda=(A,g)\) uniformly from the
full catalogue.

The probability that \(A\) contains all axes of \(\delta\) is

\[
 {\binom{V-q}{r-q}\over\binom Vr}
 ={(r)_q\over(V)_q}.                                  \tag{2.1}
\]

Conditional on this event, uniform axis permutations and endpoint
reversals act transitively on a payload owner together with an ordered
prefix of \(q\) distinct active directions.  The compiler supplies one
such prefix at every active owner.  Hence the conditional probability of
the prescribed \(\delta\) is

\[
                         {1\over(r)_q}.                \tag{2.2}
\]

Multiplying (2.1) and (2.2) proves (0.1).

For \(q=1,\ldots,H\), the events in (0.1) are nested prefix events from
one label.  In particular, for one ordered \(H\)-tuple
\((i_1,\ldots,i_H)\),

\[
 \Pr\{\delta_q=(i_1,\ldots,i_q)\text{ for every }q\le H\}
 ={1\over(V)_H}.                                      \tag{2.3}
\]

This is the exact abstract balanced nested flag law supplied by the
symmetric fractional point.

## 3. Unpointed affine-face marginal

Fix an affine \(q\)-face \(R\) of \(Q_V\).  Its direction set has size
\(q\), and it has \(2^q\) vertices.  For every vertex there are \(q!\)
orders of its \(q\) directions.  The trace injectivity of the compiler
ensures that the corresponding pointed-prefix events are disjoint when
they produce the same unpointed selected face.  Summing (0.1) gives

\[
 \Pr\{R\in{\cal F}_q(\lambda)\}
 ={2^qq!\over(V)_q}
 ={2^q\over\binom Vq},                                \tag{3.1}
\]

which proves (0.2).

The same calculation can be made in two stages:

\[
 {\binom{V-q}{r-q}\over\binom Vr}
 \cdot {2^q\over\binom rq}
 ={2^q\over\binom Vq}.                                \tag{3.2}
\]

The first factor chooses an active set containing the face directions;
the second is the exact face density of a conjugated injective
\(Q_r\)-factor.

Every selected affine face has a lower intersection and an upper union.
They are inseparable under the label.  Thus (3.1) is an exact marginal
for each sign but not an independence statement between signs or depths.

## 4. Exact physical target marginal

Inside the original product status cell, every selector axis is a split
physical pair.  It is frozen in every packet of its selector fibre.  A
lower intersection and an upper union therefore both contain exactly the
endpoint prescribed by \(z\) on every selector axis.

Consequently a physical signed-depth target \(T\) which is a candidate in
this cell determines:

* its unique selector word \(z(T)\);
* one payload affine face \(R(T)\); and
* the unique frozen word \(y\) outside the active directions, once a
  label is fixed.

Trace injectivity gives the exact deterministic occurrence equation

\[
 m_q(T)
 ={\bf1}_{\{R(T)\in{\cal F}_q(\lambda_{z(T)})\}}.      \tag{4.1}
\]

Under the fractional uniform label at every selector row,

\[
                         {\mathbb E}m_q(T)=p_{V,q}.    \tag{4.2}
\]

If \(d_q(T)\) different product cells regard \(T\) as a candidate
payload \(q\)-face, their uniform fractional load is exactly

\[
 \boxed{
 \mu_q^{\rm frac}(T)=p_{V,q}\,d_q(T).}                \tag{4.3}
\]

The rank-twisted cross-correlation formula determines \(d_q(T)\); it
need not be constant.  Hence the selector catalogue scales the physical
candidate degree but does not flatten it.

Now fix one payload face \(R\) and sum (4.1) over selector words:

\[
 \sum_{z\in Q_B}m_q(z,R)
 =\sum_z{\bf1}_{\{R\in{\cal F}_q(\lambda_z)\}}.        \tag{4.4}
\]

An OA can make (4.4) close to \(2^tp_{V,q}\).  But the left side counts
the distinct physical targets \((z,R)\).  For any one of them, (4.1)
still has only the single row \(z\).  Equation (4.4) is therefore an
aggregate cylinder marginal, not targetwise multiple coverage.

This is the precise reason that a selector OA alone cannot beat the
Poisson hole scale across physical targets.

## 5. Necessary grouping condition for a prescribed flag table

Suppose an abstract integral nested resolution prescribes, for every
owner \((z,v)\), nested direction sets

\[
 D_1(z,v)\subset\cdots\subset D_H(z,v),
 \qquad |D_q(z,v)|=q.                                 \tag{5.1}
\]

If it is realized by the selector-fibre tiling, then all these directions
must lie in the one active set assigned to the fibre:

\[
 D_H(z,v)\subseteq A_z\qquad(v\in Q_V).               \tag{5.2}
\]

Taking the union over \(v\) proves (0.4).

Thus a flag table which is direction-balanced within every selector
fibre, in the strong sense that every payload direction occurs at least
once, is impossible when \(r<V\).  A realizable table must be highly
segregated: the selector word first chooses an \(r\)-set, and all flags
in its entire \(2^V\)-owner cylinder remain inside that set.

There is a second consistency condition.  If one compiler conjugate
\(g_z\) is used for all packets in the fibre, then after projection to
\(A_z\) the prefix function may depend only on the active word
\(v|_{A_z}\), not on the frozen word \(v|_{[V]\setminus A_z}\), and it
must be an affine conjugate of the base compiler.  Allowing a separate
\(g_{z,y}\) for every packet removes the frozen-word independence
condition, but not the common-support condition (0.4).

These are integral grouping constraints.  They are invisible in
one-point axis marginals.

## 6. The abstract marginal integer program

Let \(M=2^t\), and let \(x_{z,\lambda}\in\{0,1\}\) indicate the label
assigned to selector word \(z\).  The row constraints are

\[
 \sum_{\lambda\in{\cal L}}x_{z,\lambda}=1
 \qquad(z\in Q_B).                                    \tag{6.1}
\]

For an abstract payload owner \(v\), ordered prefix \(\delta\), and
depth \(q\), exact uniform prefix marginals would require

\[
 \sum_{z,\lambda:\,\delta_q^\lambda(v)=\delta}
 x_{z,\lambda}
 ={M\over(V)_q}.                                      \tag{6.2}
\]

The balanced floor/ceiling version replaces the right side by its two
adjacent integers.  The same label variable occurs in every equation
for every depth, so nesting is retained exactly.

Exact equality in (6.2) has the necessary divisibility condition

\[
                         (V)_q\mid M.                 \tag{6.3}
\]

Since \(M\) is a power of two, (6.3) fails generically as soon as
\((V)_q\) has an odd factor.  This does not obstruct floor/ceiling
balance, but it rules out an exact equal-load OA with the proposed
number of binary selector rows.

More importantly, the constraint matrix is not totally unimodular.
Take \(r\ge2\), fix an \((r-2)\)-set \(K\), and choose three outside
directions \(i,j,k\).  Restrict to the three active sets

\[
 K\cup\{i,j\},\qquad K\cup\{i,k\},\qquad
 K\cup\{j,k\}.
\]

On the three depth-one direction-incidence rows \(i,j,k\), their matrix
is exactly (0.5), whose determinant is \(-2\).  Compiler conjugates only
refine these columns, so the obstruction persists in the full nested
flag matrix.

Therefore neither a network-flow theorem nor total unimodularity rounds
the symmetric fractional point automatically.

## 7. The actual global grouped covering program

Index the large product cells by \(c\).  For every candidate physical
target \(T\), let \(z_c(T)\) be its unique selector word in cell \(c\)
when it is candidate there.  Put

\[
 a_{c,z,\lambda}^{q,\epsilon}(T)
 ={\bf1}_{\{T\text{ is the signed depth-}q
                 \text{ trace under }\lambda\}}.
\]

The true selector problem has binary variables
\(x_{c,z,\lambda}\) with

\[
 \sum_\lambda x_{c,z,\lambda}=1                       \tag{7.1}
\]

and physical target loads

\[
 \boxed{
 \mu_q^\epsilon(T)
 =\sum_{c:\,T\text{ candidate in }c}
   \sum_\lambda
   a_{c,z_c(T),\lambda}^{q,\epsilon}(T)
   x_{c,z_c(T),\lambda}.}                             \tag{7.2}
\]

Avoiding holes asks for the appropriate lower bounds on (7.2)
simultaneously for all signs and depths, with one common label variable
across the nested tower.

An OA constructed separately inside each cell controls sums over all
\(z\), such as (4.4).  Equation (7.2) instead samples one prescribed row
from each candidate cell.  This transversal sampling is the integral
grouping obstruction.

The symmetric fractional assignment gives (4.3), but even fractional
target feasibility additionally requires

\[
                         p_{V,q}d_q(T)\ge1             \tag{7.3}
\]

or an appropriate quota-splitting analogue.  Proving only the average of
(7.3) is again potential reachability, not Hall.

## 8. Certified boundary

Proved:

1. selector-dependent active sets and compiler conjugates preserve exact
   ownership;
2. the full symmetric catalogue has the exact pointed nested marginal
   (0.1);
3. every affine face has exact marginal (0.2);
4. every physical target is tied to one selector row in each candidate
   cell, as in (0.3);
5. prescribed integral flags must satisfy the common-support grouping
   condition (0.4); and
6. the marginal matrix contains a determinant-two minor and is not TU.

Not proved:

1. targetwise fractional feasibility (7.3) for the rank-twisted
   candidate degrees;
2. an integral solution of the grouped program (7.1)--(7.2);
3. an OA whose transversal restrictions solve that grouped program; or
4. \(o(W)\) simultaneous lower/upper holes.

The selector entropy is therefore real but not yet usable as independent
target entropy.  A positive theorem must couple labels across product
cells according to their common physical targets, or alter the selector
construction so that one target is not pinned to a single row.
