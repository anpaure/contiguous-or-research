## 1. Order-type audit

For `1<=j<d`, both filler intervals

\[
                         F[1,j],\qquad F[j+1,d]
\]

are nonempty and disjoint.  The two canonical values have the same base,
so each has an element outside the other.  They are incomparable.

The first-exit theorem gives `R_i subset V_i` with one-element difference.
Every coordinate permutation preserves inclusion.  Swapping coordinate
roles changes the direction of the comparable pair but cannot make it
incomparable.  Thus no direct value-preserving lift exists.

The canonical cross pair also has opposite phase tags, while the two
first-exit terminals lie in one fixed phase bundle.  Hence a phase-
preserving direct lift fails independently of comparability.  With no
accepted direct edge, all `2(d-1)` canonical logical tickets are loops and
the literal direct-lift deficiency is exactly `2d-2`.

The no-go is not extended to arbitrary routes which change values along
the way.  Such a route must prove semantic equivalence to the canonical
ticket and is correctly isolated as the missing converter.

## 2. Acceptance-universality audit

The terminal Rado theorem explicitly forms menus after a complete cap state
has fixed occurrence labels, terminal types, guards, and structural zeros.
The first-exit theorem constrains the bundle records but places no axiom on
which ticket accepts which record.  Filtering ticket menus by an arbitrary
bipartite edge set therefore proves a logical nonimplication: geometry
alone does not force a graph class.

This argument is not used to assert that every filter is generated by the
canonical OR compiler.  It only shows that any positive interval/laminar
claim needs an additional canonical type hypothesis.

## 3. Ferrers deficiency audit

Under `x~i iff a_x<=h_i`, ticket neighborhoods are the nested sets

\[
                         E_a=\{i\notin Z:h_i\ge a\}.
\]

For any nonempty ticket set `X`, its union neighborhood is `E_t`, where
`t=min_(x in X)a_x`, and `X subseteq I_t`.  This bounds its Hall deficit by
`A(t)-H_Z(t)`.  At an attained requirement, taking `X=I_t` attains the
candidate.  At a nonattained threshold, `A` is unchanged on moving upward
while `H_Z` can only decrease, so that candidate cannot be the unique
maximum.  Hence the displayed maximum is exact.  The `t=2` row includes
total right-shore capacity, so no separate cardinality term is missing.

## 4. Run-histogram audit

A run of length `L` has exit distances `L+1,L,...,2`.  The count at least
`t` is `(L-t+2)_+`.  At `t=3` this is `L-1`; summing gives `W-J`.
Upper surjectivity implies `J>=binom(2r-1,r+1)`, and the binomial ratio gives

\[
 W-{2r-1\choose r+1}={2W\over r+1}.
\]

Longer-threshold counts are no larger.  Removing two seam indices reduces
each count by at most two.  All histogram inequalities are therefore in the
correct direction.

The theorem correctly makes no positive lower-bound claim for `H(3)`.
Upper values may repeat in separated runs, so multiplicity surplus does not
force a plateau.
