# Hostile audit of the thirteen-port / constant-D5-bank scale dichotomy

**Date:** 2026-08-14  
**Verdict:** **PASS in the stated architecture.**  The thirteen universal
ports can coalesce unbounded native arborescence incidence degree, but the
coalesced Euler theorem never duplicates an occurrence and preserves no
proper-upper ticket automatically.  A fixed 226-package D5 atlas is therefore
a plausible constant-size *local* actuator only; it cannot complete the
`Cat_(m-6)` canonical upper-hole family.  Any such completion needs
Catalan-scale exceptional owner occurrences.

## 1. The two notions of scale are correctly separated

The local flat atlas has a fixed bipartite incidence graph:

```text
226 router vertices of degree 3,
477 token vertices with degrees 1:292, 2:169, 3:16,
678 incidences, 25 tree blocks, 8 unicyclic K2,2 cores.
```

Thus the proposed local selector has bounded incidence degree.  The exact
arithmetic `461=292+169` and `16` supports one prospective C6-class collar
for every degree-one/two token and one prospective C8-class collar for every
degree-three token.  The source correctly imports the pseudoforest audit's
scope: these are menu targets, not proved q1-exact collars.

Nothing in this graph forces 226 packages to be repeated once per edge of
the native Catalan arborescence.  If one complete cut-open atlas has already
been embedded and its tickets are protected, the coalesced Euler theorem can
reuse thirteen native starts for arbitrarily many arborescence incidences.
The source states this only conditionally and lists the missing insertion,
joint-history, resource, and upper-ticket hypotheses.

## 2. Coalesced histories do not multiply occurrences

The coalesced Euler theorem's reuse of an incoming edge is a successor-swap
handle reuse.  After all swaps, the handle remains one labelled occurrence
with one predecessor and one successor.  Every other labelled edge also
appears once.  Therefore the final owner chronology remains degree two.

This distinction validates the source's central warning:

```text
unbounded incidences at one history != unbounded copies of one owner socket.
```

It also blocks a second overclaim.  The thirteen-port theorem preserves the
source deck only through width `d+1`; the immediate-upper row has width
`d+2`.  Installing a protected upper edge before the arborescence does not
prove that the later Euler tour retains it.  An avoidance or protected-ticket
extension is still required.

## 3. Exceptional-edge counting proof

In the joint range of the thirteen-port and absolute-portal theorems, the
family

\[
 {cal U}_m=\{(1100)^2 1111V:V\in D_{m-6}\}
\]

has exactly `Cat_(m-6)` distinct members.  None occurs on an old canonical
edge, and none can occur on a literal common-history seam between two
canonical owner occurrences.

Let `S` contain every owner occurrence incident with a non-common-history
package/collar/dilation edit.  Under the source's explicit architectural
hypothesis, any witness outside the edge boundary of `S` would be either old
canonical or a forbidden common-history seam.  Hence every target needs a
distinct witnessing edge incident with `S`.

A degree-two graph has at most `2|S|` incident edge occurrences at `S`.
Therefore

\[
 |S|\ge \operatorname{Cat}_{m-6}/2.
\]

This argument allows all possible collisions in the upper values and is
therefore an upper bound favorable to the proposed compiler.  It remains
valid when one Euler handle is reused sequentially, because only the final
degree matters.

If `P_m` disjoint packages contribute at most 36 exceptional owners each,
then `|S|<=36P_m`, giving the exact lower bound

\[
 P_m\ge\lceil\operatorname{Cat}_{m-6}/72\rceil.
\]

The conclusion is Catalan scale up to a constant, not literally one package
for each hole.  The source makes this distinction explicitly.

## 4. Numerical and collar-budget checks

The H100 verifier independently reconstructs the flat incidence degrees and
checks:

```text
router package owners             226*36 = 8,136
prospective collar owners     461*6+16*8 = 2,894
generous total exceptional owners            11,030
degree-two edge capacity                       22,060.
```

The router-only edge capacity `16,272` is first below the hole count at
`m=16`, where `Cat_10=16,796`.  Even the generous router-plus-collar capacity
is first below it at `m=17`, where `Cat_11=58,786`.  The source correctly
labels these as arithmetic thresholds independent of the joint hypothesis;
for fixed `d>=4`, the thirteen-port inequality starts later.  Consequently
the asymptotic contradiction is unaffected.

Charging all collar owners as exceptional is deliberately generous.  A real
graft may touch more context owners, but any uniformly bounded charge merely
changes the denominator constant and cannot change Catalan growth.

## 5. Exact remaining gate

The result proves neither a positive 226-package compiler nor impossibility
of a Catalan tensor.  The two honest remaining statements are:

1. a single local D5 actuator follows from the four protected-insertion
   hypotheses in the source; and
2. complete asymptotic upper coverage needs a context-tensored exceptional
   bank of size `Omega(Cat_(m-6))`, plus a theorem preserving its upper
   tickets through native Euler fusion.

The local maximum-degree-three pseudoforest is useful for an SDR/LLL attack,
but a separate context-separation theorem must prevent cross-copy resources
from making the tensor dependency graph Catalan-degree dense.
