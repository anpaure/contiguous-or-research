## 1. Monotone full-block admissibility

Let an old source word have letters `A_p` and caps `P_p`, with
`A_p subseteq P_p`.  At selected positions replace `A_p` by a nonempty
consecutive block

\[
              B_p=(B_{p,1},\ldots,B_{p,l_p}),
              \qquad\bigcup_tB_{p,t}\subseteq A_p,            \tag{1.1}
\]

and put cap `P_p` on every member of that block.  Map an old interval to the
new interval containing every complete replacement block which it met.

### Theorem 1.1 (monotone full-block injection)

The full-block map `Phi` is injective and, for every old interval `J`,

\[
 \operatorname{Core}_{new}(\Phi J)
   \subseteq\operatorname{Core}_{old}(J),
 \qquad
 \operatorname{Cap}_{new}(\Phi J)
   =\operatorname{Cap}_{old}(J).                         \tag{1.2}
\]

Consequently every old containment-graph matching edge transports
injectively.  Intervals trimming a replacement block are outside the image
of `Phi`, so any packet matching supported only on such side cells is
cell-disjoint from the transported old matching.

#### Proof

The ordered list of old positions met by an interval is recovered from its
full-block image, proving injectivity.  Taking unions in (1.1) gives the
first inclusion in (1.2).  Repeating a cap does not change its union, giving
the equality.  The matching and side-cell conclusions follow immediately.
\(\square\)

This theorem deliberately weakens the usual full-block hypothesis from
equality in (1.1) to containment.  The price is that it proves graph
admissibility, not simultaneous source-row equality.  If admissibility also
contains a width, deadline, boundary or other address guard, its value on
`Phi(J)` is an additional hypothesis.  In the endpoint construction exactly
the `2d+2` old intervals `[0,j]` change width.

### Corollary 1.2 (exact common-`Q` boundary)

If equality holds in (1.1) at every refined position, every transported old
row recovers its old source contribution and the repository's full-block
background theorem applies.  If strict containment holds anywhere, exact
background reconstruction is instead the maximal-word condition

\[
       S_R=E_R\cup\bigcup_{p\in J_R}K_p                 \tag{1.3}
\]

for every transported row `R`, using the packet-constrained maximal letters
`K_p`.  Containment (1.2) alone does not imply (1.3).

## 2. Exact endpoint-socket address map: one suffix ray only

Only old source position zero is split.  Thus an old interval `[i,j]` maps

\[

 \begin{cases}

 \end{cases}                                             \tag{2.1}

\[

No address in (2.2) lies in (2.1): images starting at zero include the whole
split block, while every other image starts at least at two.  Their literal

For the two phase short paths, take the pointwise union of their old cap

in both phases in this single common containment **supercap**.  This is an
unguarded graph-containment state, not yet a complete legal common-`Q`

## 4. Triangular cap gate

Write `E` for the old maximal source and `A` for the unsplit planted source.
In both phases,

\[
       A_p\subsetneq E_p\quad(0\le p<d),
       \qquad A_p=E_p\quad(p\ge d).                    \tag{4.1}
\]

The complete finite replay gives the sharper address identity

\[
 \operatorname{OR}_A(i,j)\ne\operatorname{OR}_E(i,j)
 \quad\Longleftrightarrow\quad0\le i\le j<d.          \tag{4.2}
\]

Thus the entire **fixed-source core discrepancy** is a prefix Ferrers
triangle of size `binom(d+1,2)`.  It is not spread through the baseline
word.  This localizes the rows which lose literal core before common-`Q`
selection, but it does not permit deleting all other rows from the
maximal-word system.  Enlarging a live source letter inside its cap to repair
one triangular row can change an overlapping row outside the triangle.
Accordingly the proof-safe next test keeps:

1. the triangular transported rows as the active deficit bank;
2. every other selected transported matching equality as a guard on
   enlargement;
3. all incident owner rows and ray/boundary sidecars; and
4. the complete address guards from item 3 of Section 0.

Rows outside the triangle transport literally only for the fixed planted
source `A`, before any common-`Q` enlargement.

Equation (4.2) is audited for `2<=d<=12`; an all-`d` proof is not asserted.
The attempted `d<=64` discovery stress exceeded its allotted run before
emitting a new certificate, so its status is `UNKNOWN`, not a negative
