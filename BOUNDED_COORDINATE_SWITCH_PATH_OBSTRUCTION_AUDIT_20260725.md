# Independent audit of the aligned-support multistep obstruction

Date: 2026-07-25

Audited file: BOUNDED_COORDINATE_SWITCH_PATH_OBSTRUCTION_20260725.md.

## Verdict

**PASS, with one harmless \(b=0\) convention to state explicitly.** The
row-lineage lemma, invariant-target construction, generalized Catalan
coefficient, uniform asymptotic, and logarithmic support threshold are
correct.

For \(b=0\), the series \((zC)^0=1\) represents the empty prefix, not the
class of all primitive prefixes with a vacuous initial condition. The
statement is fixed by taking the empty prefix when \(b=0\), and primitive
prefixes beginning with \(1^b\) when \(b\ge1\).

## 1. Row lineage

For a row \(E\) and transposition \(\tau=(x\ y)\), the \(n\) middle windows
have total \(x,y\)-incidence \(2m=n-1\). Hence one contains both or neither
coordinate and is \(\tau\)-fixed. This window directly joins \(E\) to
\(\tau E\) in the overlap graph.

Choosing component sides therefore maps each row bijectively to \(E\) or
\(\tau E\). Iteration gives one descendant \(g_EE\), where \(g_E\) lies in
the group generated by the transpositions. If their common support is
\(B\), then \(g_E\in\operatorname{Sym}(B)\).

## 2. Prefix enumeration and invariant targets

For \(b\ge1\), primitive Dyck prefixes with \(b\) prescribed initial rises
have generating function

\[
 H_b(z)=z^bC(z)^b=(zC(z))^b.
\]

Their complemented words begin with \(b\) zeroes, so the complementary
lower target contains all of the aligned support \(B\) and is fixed by
\(\operatorname{Sym}(B)\). Every row descendant therefore remains an owner
of the same target.

Appending the semilength-four seed and an arbitrary Dyck suffix gives

\[
 z^{b+4}C(z)^{b+1}.
\]

Thus

\[
 I_{m,b}
 =[z^{m-b-4}]C(z)^{b+1}
 =
 \frac{b+1}{2m-b-7}
 \binom{2m-b-7}{m-b-4}.
\]

Primitive-prefix decoding and bijective row lineage preserve packet
disjointness through every switch step. The robust distance inequality
follows because one subsequent row deletion hits at most one packet.

## 3. Uniform asymptotic

Dividing the exact coefficient by
\(\operatorname{Cat}_m=(m+1)^{-1}\binom{2m}{m}\) and expanding the three
finite factorial products gives, uniformly for \(b=o(\sqrt m)\),

\[
 \frac{I_{m,b}}{\operatorname{Cat}_m}
 =
 \frac{b+1}{256\,2^b}
 \left(1+O\left(\frac{(b+1)^2}{m}\right)\right).
\]

Therefore the packet target \(o(\operatorname{Cat}_m/\sqrt m)\) requires

\[
 \frac{2^b}{b+1}\gg\sqrt m,
\]

equivalently

\[
 b-\frac12\log_2m-\log_2(b+1)\to+\infty.
\]

The rough threshold
\(\frac12\log_2m+\log_2\log m+\omega(1)\) is correct.

For fixed \(b\), multiplying the recursive matching by
\((zC)^b=2^{-b}(1-b\sqrt{1-4z}+O(1-4z))\) gives the stronger density

\[
 2^{-b}\left(\frac{275}{19321}+\frac b{139}\right).
\]

## 4. Scope

The alignment hypothesis is essential and is stated correctly in the
audited report. Simultaneously relabelling the support also relabels the
canonical factor; it does not prove the same estimate for an arbitrary
support subset relative to one fixed canonical labelling.
