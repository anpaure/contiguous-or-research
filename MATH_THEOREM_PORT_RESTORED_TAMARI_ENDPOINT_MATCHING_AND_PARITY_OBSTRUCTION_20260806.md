# Endpoint matching and parity obstruct Tamari slot-transitivity

## Status

The port-restored four-row Tamari associator has zero immediate-upper q1
current, but it can change the internal order of four shortest-wreath
paths.  This note computes that action exactly.

For a complement Johnson geodesic, pair each deleted endpoint coordinate
with the coordinate inserted in the same step.  The port-restored
associator preserves this exchange matching on every named row.  It only
permutes the four exchange tokens, by

\[
 \text{right rotation},\quad(12),\quad(23),\quad(23)
\tag{0.1}
\]

on the rows `A,L,C,D`, respectively.  All four permutations are odd.

Consequently every all-dimensional tensor preserves:

1. the rowwise endpoint pair and exchange matching; and
2. the product of the exchange-order parities over all opened rows.

The graph generated by physically planted port-restored associators is
therefore not slot-transitive, even in a role-complete unrestricted host.
It cannot realize an isolated odd reordering of one wreath, and it cannot
reach a coordinate conjugate which changes a row's exchange matching.

This is a host-state obstruction, not a q1-current obstruction.  It does
not rule out using native inverse-pair moves as additional matching-changing
generators, nor does it prove that the q1 squares required for coverdown lie
in different components.  It proves that the four-row associator alone is
not the missing slot-transitivity theorem.

No computation or search is used.

## 1. Exchange words of complement geodesics

Let

\[
                 P=(P_0,P_1,\ldots,P_r)
\tag{1.1}
\]

be a shortest Johnson path from an `r`-set `S=P_0` to its complement
`S^c=P_r` on a `2r`-coordinate ground.  At step `t`, write

\[
 d_t\in P_{t-1}-P_t,
 \qquad
 i_t\in P_t-P_{t-1}.
\tag{1.2}
\]

Geodesicity implies that `d_1,...,d_r` enumerate `S` and
`i_1,...,i_r` enumerate `S^c`.  Define

\[
 \eta_P:S\longrightarrow S^c,
 \qquad \eta_P(d_t)=i_t,
\tag{1.3}
\]

and call

\[
                e(P)=((d_1,i_1),\ldots,(d_r,i_r))
\tag{1.4}
\]

the ordered exchange word.  The endpoint `S`, the bijection `eta_P`, and
the order of its `r` graph edges reconstruct `P` literally.

Thus complement geodesics with one fixed endpoint pair split first by the
`r!` possible exchange matchings and then by the `r!` possible orders of a
fixed matching.

## 2. Exact action of the base associator

Use the negative packet `mathcal P^-` and the port-restored packet
`mathcal P^*`.  Reading consecutive differences in the four displayed rows
gives the following exchange words.

### Lemma 2.1 (literal action table)

The negative and restored exchange words are

\[
\begin{array}{c|c|c}
 &e(P^-)&e(P^*)\\ \hline
A&(5\!\to\!4, 2\!\to\!7, 1\!\to\!3, 6\!\to\!8)
 &(6\!\to\!8, 5\!\to\!4, 2\!\to\!7, 1\!\to\!3)\\
L&(4\!\to\!8, 5\!\to\!6, 2\!\to\!7, 1\!\to\!3)
 &(5\!\to\!6, 4\!\to\!8, 2\!\to\!7, 1\!\to\!3)\\
C&(5\!\to\!4, 7\!\to\!8, 2\!\to\!6, 1\!\to\!3)
 &(5\!\to\!4, 2\!\to\!6, 7\!\to\!8, 1\!\to\!3)\\
D&(2\!\to\!4, 3\!\to\!8, 1\!\to\!6, 7\!\to\!5)
 &(2\!\to\!4, 1\!\to\!6, 3\!\to\!8, 7\!\to\!5).
\end{array}
\tag{2.1}
\]

Hence each named row has the same endpoint and the same exchange matching
in the two phases.  On the token order the action is

\[
 \rho=(1\ 2\ 3\ 4)^{-1},qquad
 \tau_{12},qquad
 \tau_{23},qquad
 \tau_{23},
\tag{2.2}
\]

on `A,L,C,D`, respectively.

#### Proof

For example, the negative `A` row is

\[
 1256,1246,1467,3467,3478,
\]

so its four exchanges are

\[
 5\to4,quad2\to7,quad1\to3,quad6\to8.
\]

The restored `A` row is

\[
 1256,1258,1248,1478,3478,
\]

and has the right-rotated list in (2.1).  The other three rows give the
remaining entries by the same one-step subtraction.  Equality of each set
of directed pairs proves matching preservation; their displayed orders
give (2.2).  \(\square\)

Every permutation in (2.2) is odd: a four-cycle has sign `-1`, as does a
transposition.

## 3. Tensor action

In semilength `r>=4`, the tensor appends one common complement-geodesic
tail after the four base exchanges.  Its exchange tokens are fixed
literally in both phases.

### Theorem 3.1 (all-dimensional action)

On every named row of the tensor:

1. the endpoint pair is fixed;
2. the full `r`-edge exchange matching is fixed;
3. the first four exchange tokens are permuted as in (2.2); and
4. exchange tokens `5,...,r` are fixed.

#### Proof

The base assertion is Lemma 2.1.  The tensor construction uses the same
terminal base state and the same fresh tail geodesic in both phases, so its
remaining directed exchange pairs and their order agree row by row.
\(\square\)

Coordinate relabelling conjugates the exchange matching and relabels every
token, but it does not change the four order permutations in (2.2).

## 4. Two exact orbit invariants

Consider a family of opened complement paths whose endpoint pairs are
distinct, so the endpoints label the rows.  Fix one reference order on the
edges of every row's exchange matching.

For a factor state `F`, let `sigma_P` be the order permutation of row `P`
relative to its reference, and define

\[
                         \epsilon(F)
       =\prod_{P}\operatorname{sgn}(\sigma_P)\in\{+1,-1\}.
\tag{4.1}
\]

### Theorem 4.1 (matching and global-parity invariance)

Every sequence of physically planted port-restored four-row associators
preserves:

\[
 \bigl\{(P_0,P_r,\eta_P):P\text{ a named row}\bigr\}
\tag{4.2}
\]

row by row, and preserves `epsilon(F)`.

#### Proof

Theorem 3.1 proves (4.2) for one move, hence for every composition.  One
move applies four odd order permutations, so it multiplies (4.1) by
`(-1)^4=+1`.  \(\square\)

### Corollary 4.2 (failure of full slot-transitivity)

The port-restored associator graph has at least two order components inside
every nontrivial fixed-matching fibre.  In particular it cannot perform one
isolated adjacent transposition on one row while returning every other row
to its previous order.

It also cannot reach any prospective coordinate-conjugate host whose
rowwise exchange matching differs from (4.2).

#### Proof

An isolated adjacent transposition reverses `epsilon`.  A different
exchange matching violates the first invariant.  \(\square\)

The parity assertion remains true in a role-complete abstract host in which
every support-compatible relabelling of the packet is declared available:
every generator still changes the parity of exactly four rows.

## 5. Action on exposed inverse-pair slots

For a path state `(eta,sigma)`, let

\[
                         \mathcal R(\eta,\sigma)
\tag{5.1}
\]

denote the set of separated-double-swap starts which participate in a
native inverse pair with another row.  Theorem 3.1 gives an exact state
model for the associator action on this slot graph:

\[
 (\eta_A,\sigma_A),\ldots,(\eta_D,\sigma_D)
 \longmapsto
 (\eta_A,\rho\sigma_A),
 (\eta_L,\tau_{12}\sigma_L),
 (\eta_C,\tau_{23}\sigma_C),
 (\eta_D,\tau_{23}\sigma_D),
\tag{5.2}
\]

up to the convention for left versus right multiplication.  The exposed
slot set is recomputed from the four new orders, but all four `eta` labels
remain fixed.

Therefore the dynamic q1 span from the preceding note can enlarge only by
discovering inverse squares inside the fixed exchange-matching sector
(4.2), and only in the global parity component (4.1).  The associator does
not provide access to the full set of prospective coordinate conjugates.

This is an obstruction to **full host-state transitivity**.  It is not yet
an obstruction to q1 coverdown: it remains possible that every required
balanced square has some representative inverse slot inside one matching
and parity sector.

## 6. Remaining sharpened theorem

The next question no longer needs the entire coordinate-conjugate atlas.
It is the smaller relative statement:

> **Fixed-matching slot sufficiency.**  In one endpoint/exchange-matching
> sector and one global parity component, the union of inverse-pair slots
> exposed by associator sequences spans every q1 current needed to reach a
> last-provider-safe cap-two upper histogram.

A positive theorem would bypass the orbit invariants because q1 targets do
not remember the endpoint matching.  A negative theorem must exhibit a
linear q1 functional which vanishes on every inverse square realizable in
one sector, not merely on the time-zero inverse pairs.

Native inverse-pair moves themselves may change the matching sector; that
action has not been included here.  Any combined dynamic theorem must
compute it explicitly before using (4.2) as an invariant of the larger
move graph.
