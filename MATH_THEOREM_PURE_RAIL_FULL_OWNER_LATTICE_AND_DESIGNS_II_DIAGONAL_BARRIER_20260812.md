# Nonmaximal pure rails generate the full named-owner lattice, but not the positive factor

**Date:** 2026-08-12
**Method:** exact-distance Johnson connectivity, integral point-kernel
generation, and a quantitative audit of the labelled-complex decomposition
theorem
**Status:** unconditional signed-lattice theorem for the pure-rail owner
columns.  Together with optional marking it eliminates every modular
character on owners, designated lower targets, and whole-component trace
boundary.  It does **not** prove nonnegative/disjoint packing, palette or
socket exactness, upper witness preservation, or the terminal common cap.

## 1. Pure-rail columns

Put

\[
 q=d+1,\qquad c=R-q,\qquad M=k-c=k-R+q.
\tag{1.1}
\]

For a period

\[
 2(q+1)\le N\le M,
\tag{1.2}
\]

choose a core \(C\), \(|C|=c\), a toggle set \(T\), \(|T|=N\), and a
cyclic order \(\sigma\) of \(T\).  The corresponding named-owner column is

\[
 f(C,T,\sigma)
 =\sum_{I\in\mathcal I_q(\sigma)}e_{C\cup I}
 \in\mathbb Z^{\binom{[k]}R}.
\tag{1.3}
\]

Let \(\mathcal L_{\rm own}\) be the integer lattice generated by all such
columns, allowing every legal period and every embedding.  Write

\[
 P_R:\mathbb Z^{\binom{[k]}R}\longrightarrow\mathbb Z^k,
 \qquad P_Re_A={\bf1}_A
\tag{1.4}
\]

for point incidence.

Throughout the main theorem assume

\[
 d\ge1,\qquad c\ge1,\qquad M-2\ge2(q+1).
\tag{1.5}
\]

These inequalities hold for the central parameters for all sufficiently
large \(k\).  Notice that (1.5) implies

\[
 k-R\ge d+3.
\tag{1.6}
\]

## 2. Restricted carousel trades generate the complete point kernel

For distinct \(x,y\in[k]\) and an \((R-1)\)-set \(A\) avoiding them, put

\[
 \delta_{xy}(A)=e_{A\cup\{x\}}-e_{A\cup\{y\}}.
\tag{2.1}
\]

### Lemma 2.1 (every distance-\(d\) context relation is a rail trade)

If \(A,B\in\binom{[k]\setminus\{x,y\}}{R-1}\) and

\[
 |A\cap B|=c=R-d-1,
\tag{2.2}
\]

then

\[
 \delta_{xy}(A)-\delta_{xy}(B)\in\mathcal L_{\rm own}.
\tag{2.3}
\]

#### Proof

Write

\[
 C=A\cap B,\qquad L=A\setminus C,\qquad S=B\setminus C.
\]

Then \(|L|=|S|=d\), and the four displayed sets are pairwise disjoint
apart from the common core.  Choose any legal period \(N\).  Its toggle
set may be chosen to contain

\[
 L\mathbin{\dot\cup}\{x,y\}\mathbin{\dot\cup}S,
\]

because this set has size \(2d+2=2q\), while \(N\ge2q+2\) and
\(N\le M=|[k]\setminus C|\).  Give the toggle cycle the local order

\[
 L,\ x,\ y,\ S
\tag{2.4}
\]

and put all remaining toggle labels in the exterior gap.  Interchanging
the adjacent labels \(x,y\) changes exactly the two owner windows ending
at \(x\) and beginning at \(y\).  The old-minus-new owner current is

\[
 e_{A+x}+e_{B+y}-e_{A+y}-e_{B+x}
 =\delta_{xy}(A)-\delta_{xy}(B).
\]

It is the difference of two legal pure-rail columns.  \(\square\)

### Lemma 2.2 (the exact-distance context graph is connected)

For fixed \(x,y\), let \(G_{xy}\) have vertex set

\[
 \binom{[k]\setminus\{x,y\}}{R-1}
\]

and join \(A,B\) when \(|A\cap B|=c\).  Under (1.6), \(G_{xy}\) is
connected.

#### Proof

It is enough to connect every adjacent pair in the ordinary Johnson graph,
which is connected.  Write such a pair as

\[
 A=H\cup\{a\},\qquad B=H\cup\{b\},\qquad |H|=R-2.
\]

Choose \(C_0\subset H\) with \(|C_0|=c\).  In the ground set with
\(x,y\) removed, the complement of \(A\cup B\) has size

\[
 (k-2)-R=k-R-2\ge d+1.
\]

Choose a \(d\)-set \(D\) there and put \(Z=C_0\cup D\).  Then
\(|Z|=c+d=R-1\), while

\[
 |A\cap Z|=|B\cap Z|=c.
\]

Thus \(A-Z-B\) is a two-edge path in \(G_{xy}\).  Replacing every
Johnson edge by such a path proves connectedness.  \(\square\)

### Theorem 2.3 (pure-rail trades generate the point kernel)

\[
 \boxed{\ker_{\mathbb Z}P_R\subseteq\mathcal L_{\rm own}.}
\tag{2.5}
\]

#### Proof

Work in the quotient

\[
 \mathcal G=\mathbb Z^{\binom{[k]}R}/\mathcal L_{\rm own},
\]

writing \([A]\) for the class of \(e_A\).  Lemmas 2.1--2.2 show that
the class of \(\delta_{xy}(A)\) is independent of the context \(A\);
denote it by \(\delta_{xy}\).  A common \((R-1)\)-context avoiding three
distinct points gives the cocycle identity

\[
 \delta_{xy}+\delta_{yz}=\delta_{xz}.
\tag{2.6}
\]

Fix a point \(p\), put \(\gamma_p=0\), and put
\(\gamma_x=\delta_{xp}\).  Then

\[
 \delta_{xy}=\gamma_x-\gamma_y.
\tag{2.7}
\]

If two rank-\(R\) sets are Johnson-adjacent, (2.7) shows that

\[
 [A]-\sum_{x\in A}\gamma_x
\]

has the same value on both.  The Johnson graph \(J(k,R)\) is connected,
so there is one \(\alpha\in\mathcal G\) such that

\[
 [A]=\alpha+\sum_{x\in A}\gamma_x
\tag{2.8}
\]

for every owner \(A\).

Now take \(z=\sum_Az_Ae_A\in\ker_{\mathbb Z}P_R\).  Summing all point
equations gives

\[
 R\sum_Az_A=0,
\]

so \(\sum_Az_A=0\).  Equation (2.8) then gives

\[
 \sum_Az_A[A]
 =\alpha\sum_Az_A+
   \sum_x\gamma_x\sum_{A\ni x}z_A=0.
\]

Hence \(z\in\mathcal L_{\rm own}\).  No division in an abelian group was
used, so this is exact integral generation, not only rational spanning.
\(\square\)

## 3. The full named-owner lattice

The point image of one pure rail is

\[
 P_Rf(C,T,\sigma)=N{\bf1}_C+q{\bf1}_T.
\tag{3.1}
\]

### Lemma 3.1 (exact point image)

Under (1.5),

\[
 \boxed{
 P_R(\mathcal L_{\rm own})
 =\left\{u\in\mathbb Z^k:\sum_xu_x\equiv0\pmod R\right\}.}
\tag{3.2}
\]

#### Proof

Every column consists of \(N\) rank-\(R\) owners, so the coordinate sum
of its point image is \(RN\).  This proves containment in the right side.

Conversely, use the two legal nonmaximal periods \(M-1,M-2\).  Swapping
two coordinates between a core role and an unused role in period \(N\)
changes (3.1) by

\[
 N(e_x-e_y).
\]

Since \(\gcd(M-1,M-2)=1\), the point image contains every unit difference
\(e_x-e_y\), hence the complete zero-sum lattice.

The difference of any period-\((M-1)\) column and any period-\((M-2)\)
column has point-coordinate sum exactly \(R\).  Therefore the image also
contains some vector of sum \(R\).  Adding its multiples to the zero-sum
lattice yields every integer vector whose coordinate sum is divisible by
\(R\).  \(\square\)

### Theorem 3.2 (full owner-lattice saturation)

\[
 \boxed{
 \mathcal L_{\rm own}
 =\mathbb Z^{\binom{[k]}R}.}
\tag{3.3}
\]

In particular, the all-one named-owner demand and every individual owner
unit vector lie in the integer column lattice of nonmaximal pure rails.

#### Proof

Take arbitrary \(z\in\mathbb Z^{\binom{[k]}R}\).  Since

\[
 \sum_x(P_Rz)_x=R\sum_Az_A,
\]

Lemma 3.1 supplies \(y\in\mathcal L_{\rm own}\) with
\(P_Ry=P_Rz\).  Then \(z-y\in\ker_{\mathbb Z}P_R\), which belongs to
\(\mathcal L_{\rm own}\) by Theorem 2.3.  Thus \(z\in\mathcal L_{\rm
own}\).  \(\square\)

This strengthens the previously proved scalar, point, and standard
subset-degree gcd calculations: there is no nonstandard modular character
on the named owner shore either.

## 4. Consequence for the owner/lower/state signature

Optional lower designations are downward closed: marking or unmarking one
already-existing eligible suffix occurrence changes no owner, source word,
residence row, palette, or trace state.  Therefore the optional-mark unit
theorem gives

\[
 0\oplus e_S
\]

for every Ferrers-residual lower target \(S\).  Every whole rail is a
closed literal component and has trace boundary zero integrally.

Combining these facts with Theorem 3.2 gives the following exact result.

### Corollary 4.1

After retaining only named owners, optional designated lower targets, and
the signed trace-state boundary, the unified rail-packet lattice is

\[
 \boxed{
 \mathbb Z^{\binom{[k]}R}
 \oplus
 \mathbb Z^{\mathcal L_{\rm residual}}
 \oplus\{0\}.}
\tag{4.1}
\]

Thus any surviving modular character of the full packet system must use a
resource omitted from (4.1), such as a compulsory immediate-palette row, a
phase/socket action, a nonoptional upper ticket, or a typed common-cap
resource.

Corollary 4.1 is a signed-lattice statement.  It does not assert that the
all-one demand belongs to the **nonnegative affine semigroup** of mutually
owner-disjoint rail copies.  Affine-semigroup holes and positive
extendability remain possible even though the group quotient is trivial.

## 5. Why *Designs II* is not an available black box

Keevash's labelled-complex decomposition theorem (*The Existence of
Designs II*, Theorem 3.1) begins: for any fixed molecule parameters
\(q\ge r\) and \(D\), there are constants \(\omega_0,n_0\); it then assumes
\(n>n_0\), regularity, lattice membership, and
\((\omega,h)\)-extendability, with the displayed parameters

\[
 h=2^{50q^3},\qquad \delta=2^{-10^3q^5},
 \qquad n^{-\delta}<\omega<\omega_0(q,D).
\tag{5.1}
\]

For a faithful ground-coordinate realization of a near-maximal pure rail,
the molecule uses

\[
 U=c+N\in\{k-2,k-1,k\}
\tag{5.2}
\]

ground labels.  Thus its molecule parameter satisfies \(q_{\rm mol}=U\sim
n=k\), rather than being fixed while \(n\to\infty\).  The theorem contains
no uniform estimate in this diagonal regime.

There is also an explicit failure of its extendability premise.  In the
complete injection complex, pin \(U-1\) labels of a rail embedding and ask
to extend the last label.  This is a simple labelled extension and it has
exactly

\[
 k-U+1\le3
\tag{5.3}
\]

extensions for the three-period absorber catalogue.  The required
\(\omega\)-density for one free vertex is at least \(\omega k\).  In the
formal parameter range (5.1),

\[
 \omega k>k^{1-\delta}>3
\]

for large \(k\).  Hence the actual rail embedding complex is not
\((\omega,h)\)-extendable in the sense required by that theorem.

Encoding owners rather than coordinates as the host vertices does not
repair this invocation: pinning all but one owner of a carousel again has
far fewer than a positive fraction of the owner shore as completions, and
the Boolean intersection/ordering data must be retained as growing
colours.  A different compressed labelled complex would require a new
regularity, lattice, and extendability proof; it is not an application of
the existing theorem.

Therefore the correct conclusion is

\[
\boxed{
 \textit{Designs II handles vector-valued labels, but its fixed-molecule
 and extendability hypotheses fail for the almost-spanning rail molecule.}}
\tag{5.4}
\]

## 6. Fixed-rank atomization does not preserve the solved correlations

One might split a rail into individual de Bruijn transition arcs and apply
a fixed-size decomposition theorem to those atoms.  Two exact cautions are
load-bearing.

First, in the ground-coordinate model even one owner-bearing transition
uses a rank-\(R\) Boolean value, so its coordinate pattern still has
\(R=\Theta(k)\) labels.  It is not fixed rank in the sense of (5.1).

Second, suppose one abstracts each state or owner value to a single host
vertex.  Inside one directed simple \(N\)-cycle, a \(0\)-\(1\) subset of
its arcs has zero boundary if and only if it is empty or is the full
cycle: flow conservation at successive vertices forces every arc
indicator to be equal.  Thus grouping the original transitions while
retaining their automatic state balance recovers the growing \(N\)-arc
molecule.

Arcs from different rails can of course be balanced after new cross-rail
transitions are admitted.  But then the selected Euler components need no
longer be rail queues, so the proved simple all-width deck, residence, and
upper coverage no longer follow.  Establishing those properties for such
a fixed-atom system is precisely a new integral fusion theorem, not a
formal atomization of the fractional rail result.

## 7. Exact frontier

The following possible obstructions are now eliminated for sufficiently
large central parameters:

* scalar component-count congruence;
* every ground-coordinate congruence;
* every standard subset-degree congruence;
* every nonstandard modular character on named owners;
* every modular character on optional designated lower targets; and
* nonzero whole-component trace boundary.

The remaining owner-side statement is genuinely positive:

> Show that the all-one owner vector lies in the nonnegative semigroup of
> pairwise owner-disjoint decorated rail copies, with a robust absorber for
> every small named leave, while retaining the compulsory palette,
> upper-witness, socket, and common-cap coordinates.

Theorem 3.2 proves the exact lattice premise for such an absorber.  It does
not supply semigroup normality, resource-disjoint positive trades, or one
Euler component.  Those are now the first possible integral obstructions.
