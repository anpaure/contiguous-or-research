# Adversarial audit: clean folded-C8 endpoint, full-block transport, and triangular host gate

Date: 2026-08-01  
Lane: R independent audit  
Scope: theorem source, primary endpoint-seam catalogue, common-endpoint
negative control, and independent full-block-interface catalogue.  No new
search and no all-`d` extrapolation.

## 0. Verdict

The full-block interval-transport theorem and the exact triangular failure
of the natural maximal-source map are valid.  The frozen seam catalogue also
validly proves, for every `2<=d<=12`, a resident two-path forest with complete
local upper support and a phasewise literal one-sided suffix ray.

Two corrections were necessary.

1. The full-block-interface replay is independent for the displayed
   endpoint source, interval map, and triangular loss, but it is not an
   independent enumeration of every seam or final forest cut.  Those facts
   are certified by the primary seam catalogue.
2. Splitting `B_0=X` is compiler-exact but **not owner-neutral**.  It creates
   one additional depth-`d` owner window, replaces the first old owner by a
   two-owner endpoint ear, and only then retains the old owner tail.  Any
   physical planting theorem must accept this ear explicitly.

After these corrections the theorem has the right scoped conclusion:
prospective occurrence-level host planting plus owner/palette/residence
acceptance and zero-charge reset remain open.  Neither the clean endpoint nor
the common-endpoint cut realizes both folded cross banks in one cap/guard
state.

## 1. Valid claims

### 1.1 Simultaneous full-block transport

For a linear source word, replacing each old letter `A_p` by a consecutive
nonempty block whose union is `A_p` sends an old interval to the interval
using every subletter at each old position.  The endpoint pair of old
positions is recoverable, so the map is injective, and its OR is unchanged.
An interval using a proper side of one split block is not in this image.
Therefore a previously injective target-to-occurrence matching transports,
and private side-ray cells cannot collide with its image.

This statement is occurrence-level, not merely equality of target counters.
It assumes the host is an actual old source letter and says nothing by itself
about the depth-window owner chronology after adding source positions.

### 1.2 Primary clean-seam census

For every `2<=d<=12`, the primary catalogue has exactly

```text
candidate_seams = 2
upper_complete_resident_recyclable_seams = 2
upper_complete_resident_linear_forest_seams = 2.
```

For either seam, before the final cut the two components have sizes
`d+2,7d+22`; the edge count and lower support are both `8d+23`, hence all
retained lower colours are distinct.  Upper support is `16`.  There are
exactly `7d+9` common final cuts, and after any accepted cut the same component
sizes remain, both paths are resident, the lower support and edge count are
both `8d+22`, and upper support remains `16`.

The normalized three-edge formulas agree with every displayed catalogue row:
the host edge exchanges `a_3` for `f_(d+1)`, the repeated-upper edge exchanges
`f_0` for `f_1`, and the new seam exchanges `a_1` for `a_3` over the common
extended filler set.

### 1.3 One-sided ray addresses and raw charge

After the owner-preserving source rethread `A -> B`, the split

```text
B_0=X -> (N_(1-epsilon),N_epsilon)
```

is a genuine one-block refinement.  Its natural old-address map is

```text
[0,j] -> [0,j+1],       [i,j] -> [i+1,j+1] for i>0.
```

The `d-1` cells `[1,j]`, `2<=j<=d`, lie outside the image and are pairwise
distinct.  They form the phasewise decreasing-filler suffix ray found in the
interface catalogue.  The source-length charge is exactly `+1`.  The common
screen value `X` is already supplied by the union of the two halves, but this
does not remove the added physical address.

The canonical passive two-host module uses a different, consistent indexing:
for `1<=j<d`, its prefix/suffix cells are `[1,j]` and `[j+1,d]`.  A folded
antidiagonal is a paired two-cell ticket, never one physical cell.

### 1.4 Exact owner-ear identity

Let `T=D^dB` and let `tilde B` be the split word.  Direct window expansion
gives

\[
 D^d\widetilde B=
 \bigl(B_0\cup\cdots\cup B_{d-1},\
       N_\epsilon\cup B_1\cup\cdots\cup B_d,\
       T_1,T_2,\ldots\bigr).
\]

Thus `D^d tilde B` has one more owner than `T`.  The tail from `T_1` onward
is literal, but the first owner is replaced by two endpoint owners.  This
refutes the former wording “owner chronology is unchanged” after the split.
Only `D^dB=T` is owner-preserving.

### 1.5 Exact triangular natural-map failure

For every audited depth and both phases, the changed old addresses under the
natural split map are exactly

\[
             \{[i,j]:0\le i\le j<d\},
\]

of size `d(d+1)/2`.  Every change is a strict loss.  For `0<=i<=j<d`, the
loss is

* `F[1,d-j]` if `i=0`, in either phase;
* `F[1,d-j]` if `i>0` in phase zero; and
* `{a_3} union F[1,d-j]` if `i>0` in phase one.

Every interval ending at or after position `d` is unchanged because the
first unchanged boundary letter restores the omitted low fillers and, in
phase one, `a_3`.  The checker now contains explicit fail-closed assertions
for these formulas.  The frozen JSON already exports every changed address,
old/new value, and lost/gained coordinate set; adding the assertions does
not alter that payload.

### 1.6 Common-endpoint negative control

For each `2<=d<=12`, the common-endpoint catalogue has exactly two candidate
rethreads and reports

```text
exact_one_ray_comparators = 0
one_ray_universal_support_actuators = 0
best upper_support_after_cut = [15,15].
```

Both phase words do add the intended opposite suffix ray and preserve their
own pre-split support, but they neither reduce the residual difference to the
two prefix chains nor retain the complete upper palette.  Therefore the
common-endpoint cut is not the desired two-cross-bank actuator.

The upper-safe three-edge seam repairs the upper palette to `16`, but its
authenticated endpoint source supplies only one phasewise suffix ray.  The
second cross bank is not certified in the same component/cap state.

## 2. Corrections made

The theorem was edited as follows.

1. Replaced “independent seam audit” by the exact provenance: primary seam
   census plus independent displayed-witness/full-block replay.
2. Replaced the false post-split owner-neutrality claim by the owner-ear
   identity above, and added owner-ear acceptance to the remaining physical
   embedding gate.
3. Restricted the triangular theorem explicitly to both phases and
   `2<=d<=12`, and clarified that failure is for the natural address map; an
   unrelated address permutation is not excluded.
4. Recorded the exact scope of the common-endpoint negative control and the
   distinction between its upper-15 failure and the upper-16 safe seam.
5. Corrected the displayed `\qquad` typo and strengthened the checker with
   exact phase-dependent triangular-loss and owner-ear assertions.

## 3. Unsupported or still open

The audited material does not prove any of the following.

* the clean seam formulas for all `d` (the theorem is finite through `12`);
* a simultaneous reflected pair of clean endpoint sockets;
* both folded cross perfect matchings in one owner/cap/guard state;
* owner, lower-palette, upper-palette, and residence legality of the new
  two-owner ear;
* occurrence of the prospective word `B` as an admissible old source word;
* an alternative address return for the triangular bank;
* raw `chi=0` (the split costs one address per socket); or
* a global Catalan placement or `B(k)+O(1)` induction.

Once an actual old host and an owner-legal split are supplied, the
simultaneous full-block theorem does transport any admissible old matching
and makes the side cells private.  Before those hypotheses hold, it cannot
be used to bypass owner or topology legality.
