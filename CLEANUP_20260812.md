# Workspace cleanup and publication boundary

**Date:** 2026-08-12

Before this commit the working tree contained 151,455 untracked files,
mostly duplicated Finder copies and generated search artifacts.  The cleanup
kept every tracked artifact, the unique top-level mathematical corpus, and a
small explicit K15/K16 replay set.

Removed material:

- 70,256 byte-identical files carrying the accidental ` 2` copy suffix
  (the first 70,149 were moved to a recoverable Trash bundle with a manifest);
- the remaining untracked generated `scratch/` cache, after restoring all
  115 tracked files and the selected compact replay inputs;
- 382 top-level generated files (CNF/model/log outputs, compiled Mach-O
  binaries, and five accidental numeric files), totalling 4,991,754,362
  bytes; the exact path/size list is retained in
  `CLEANUP_20260812_GENERATED_ROOT_MANIFEST.tsv`.

The retained `scratch/` tree has 118 files and is approximately 3.0 MB.
No tracked file was deleted.  The repository intentionally excludes
multi-gigabyte solver inputs, proofs, temporary portfolios, compiled
binaries, and runtime logs; authoritative statements retain compact hashes,
sources, audits, and literal certificates instead.
