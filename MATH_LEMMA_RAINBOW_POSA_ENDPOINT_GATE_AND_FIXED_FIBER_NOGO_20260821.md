# Rainbow endpoint expansion and the fixed-fiber no-go

**Status (2026-08-21).**  The lemmas below are proved.  They isolate the
exact Posa-style consequence of maximality for a color-simple tail-MTF path.
They also show that the existing common-transformation fibers supply no
endpoint rotations at all: their exponential branch entropy and linear deck
distance live entirely over one terminal state.

## 1. The terminal fan

Let a recency state be

\[
                     \pi=(x_1,\ldots,x_n),
\]

most recent first, and put

\[
 n=2m+1,\qquad f=m+H+2,
 \qquad d=n-f+1=m-H.
\]

Assume `0<=H<=m-1`, so `1<=d<=m`.  In the DCC application
`H=o(n)`, and only there do we use `d=Theta(n)`.

The owner color is `C_m(pi)={x_1,...,x_m}`.  A legal generator `T_j`,
`f<=j<=n`, moves `x_j` to the front.  Hence its post-move owner color is

\[
 C_m(T_j\pi)=\{x_1,\ldots,x_{m-1},x_j\}.             \tag{1.1}
\]

Define the terminal fan

\[
 \mathcal N_f(\pi)=
 \{C_m(T_j\pi):f\le j\le n\}.                       \tag{1.2}
\]

It has exactly `d` members.

### Lemma 1.1 (maximal rainbow blocker)

Let `P` be a color-simple legal tail-MTF path and let `U(P)` be its set of
owner colors.  If `P` cannot be extended at its terminal state `pi`, then

\[
                         \mathcal N_f(\pi)\subseteq U(P). \tag{1.3}
\]

#### Proof

Every member of (1.2) is the color of one legal next step.  A member outside
`U(P)` would extend the color-simple path, contrary to maximality.
\(\square\)

For one endpoint this forces only `d` used colors (`Theta(n)` in the DCC
regime) and gives no information on the exponential scale
`W=binom(n,m)`.

## 2. The exact endpoint-expansion criterion

Call a family `E(P)` of terminal states a **deck-preserving endpoint family**
if, for every `rho in E(P)`, there is a specified color-simple legal
tail-MTF path `P_rho` ending at `rho` such that `U(P_rho)=U(P)`.  This
definition deliberately contains the hard part of a directed Posa rotation:
no reversal operation is assumed.

### Proposition 2.1 (rainbow Posa criterion)

If every specified `P_rho` is unextendable as a color-simple legal tail-MTF
path--as holds in particular when `P` is globally maximum-length--then

\[
       \bigcup_{\rho\in E(P)}\mathcal N_f(\rho)
       \subseteq U(P).                               \tag{2.1}
\]

Consequently, if

\[
 \left|\bigcup_{\rho\in E(P)}\mathcal N_f(\rho)\right|
       \ge(1-\eta)W,                                 \tag{2.2}
\]

then `|U(P)|>= (1-eta)W`.

#### Proof

Apply Lemma 1.1 to `P_rho` for every `rho`.  An unused fan color would
extend that specified representation and contradict its unextendability.
Taking the union proves (2.1), and (2.2) gives the final inequality.
\(\square\)

Thus a useful rotation theorem must produce many **different terminal
states whose fans cover many colors while the used deck stays fixed**.

Even changing every order above one fixed owner is insufficient.  If
`C_m(rho)=X` is fixed and `rho` ranges over all recency states above `X`, then

\[
 \bigcup_{C_m(\rho)=X}\mathcal N_f(\rho)
 =\{X-\{x\}+\{y\}:x\in X,\ y\notin X\},             \tag{2.3}
\]

which has only `m(m+1)=Theta(n^2)` members.  Indeed `x` can be placed in
position `m` and `y` in an eligible tail position, and (1.1) gives every such
neighbor.  Endpoint expansion must therefore reach exponentially many
owner fibers, not merely reorder one owner fiber.

## 3. Common-endpoint fibers are not Posa rotations

Fix a seed state `pi_0` and a block length `ell`.  A common-transformation
fiber is a family of generator words `G` for which

\[
                         w(\pi_0)=\sigma(\pi_0)
                         \qquad(w\in\mathcal G)       \tag{3.1}
\]

for one position permutation `sigma`.  Replacing one branch by another in a
larger path preserves both boundary states of that block.

### Theorem 3.1 (fixed-fiber endpoint no-go)

Any sequence of replacements inside common-transformation fibers which are
strictly internal to a path leaves its terminal state unchanged.  The same
holds for a terminal block if its seed and transformation are fixed.  Hence
the endpoint family generated by such switches is the singleton

\[
                         E(P)=\{\pi_{\rm end}\}.       \tag{3.2}
\]

If the generated path is unextendable, the resulting maximality certificate
is only the original `d`-element fan (1.2).

#### Proof

An internal replacement has the same incoming and outgoing full states as
the branch it replaces, so the suffix after the block and the global terminal
state are identical.  For a terminal block, (3.1) gives the same terminal
state directly.  Induction over replacements proves (3.2); if the path is
unextendable, Lemma 1.1 gives the last assertion.  \(\square\)

There is a second mismatch.  The proved common-endpoint deck code supplies
branches whose retained decks have replacement distance `Omega(n)`.  A Posa
rotation, as used in Proposition 2.1, must preserve the used color set.
Large deck distance is useful local mobility, but is not deck preservation.

## 4. Exact missing booster theorem

The common-endpoint results can enter a rotation-extension proof only after
one proves an additional operation of one of the following forms:

1. a two-ended splice which changes the terminal full state while preserving
   the owner deck;
2. a variable-transformation terminal fiber exposing many terminal owner
   colors with a common retained deck; or
3. a controlled augmentation which changes the deck by a prescribed small
   exchange and iterates without losing simplicity.

No current common-transformation or linear-distance-code theorem supplies
any of these.  In particular, direct whole-block replacements within fixed
common-transformation fibers have no endpoint expansion, and fiber
cardinality, entropy, and pairwise deck distance alone imply no lower bound
beyond `d` for the fan union in (2.1).  This does not rule out splices,
cuts, or coordinated multi-block operations.

The criterion controls only rank-`m` owner colors of an open path.  Even a
near-complete fan union would not by itself prove full-band simplicity,
`o(W)` all-rank defect, or cyclic closure; Proposition 2.1 is an endpoint
tool, not a coefficient-one theorem.
