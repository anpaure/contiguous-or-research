## 1. The common-`M0` q4 interface

Use the notation of
`MATH_THEOREM_QPORT_RESIDENT_RAIL_ROLE_CONVERTER_20260801.md`.  For `q=4`

\[
                         M_0(T\cap V)=T.                \tag{1.2}
\]

### Lemma 1.1 (the predecessor half is phase-common)

The `H2` and `H3` q4 states impose the same `N` partial assignments in
`M0`.

#### Proof

The rail atoms have the same direction in `H2` and `H3`, so there is
nothing to check there.  On the direct atom at port `i`,

\[
 \begin{array}{c|c|c}
  &\text{directed atom}&\text{lower colour}\\ \hline
 H_2&A_i\to B_i&A_i\cap B_i=L_i,\\
 H_3&A_i\to B_{i-1}&A_i\cap B_{i-1}=L_i.
 \end{array}                                            \tag{1.3}
\]

The tail is `A_i` in both rows.  Hence both require `M0(L_i)=A_i`.
All lower colours and tails in the q-port bank are distinct, so these
assignments form one partial incidence matching. \(\square\)

Lemma 1.1 supplies only this common partial assignment.  Extension to a
global predecessor matching is the fixed-`M0` host problem of Section 2;
it does not follow from local resource distinctness alone.

Cut one direct `H3` edge `e*=A_j->B_(j-1)`.  Retain all `N` assignments
of Lemma 1.1 in `M0`, but retain only the other `N-1` directed atoms in the
terminal arc set `Q`.

### Lemma 1.2 (terminal path versus pre-switch cycles)

After contraction of the forced `M0` edges, the `N-1` retained `H3` atoms
form one directed path.  In contrast, forcing all `H2` atoms into `Q`
forms four directed cycles and violates the graphic inequality.

#### Proof

Write the opened owner order as

\[
                         Z_0,Z_1,\ldots,Z_{N-1}.         \tag{1.4}
\]

For `i<N-1`, put `p_i=Z_i cap Z_(i+1)`, and put
`p*=low(e*)`.  The common predecessor assignments give

\[
 M_0(p_i)=Z_i,\qquad M_0(p^*)=Z_{N-1}.                 \tag{1.5}
\]

Thus the contracted links are exactly

\[
                         p_0\to p_1\to\cdots
                         \to p_{N-2}\to p^*.            \tag{1.6}
\]

For `H2`, each rail plus its direct edge is a closed port cycle.  On the
vertex set of any one port, the selected link count equals the vertex
count, contradicting `|E(S)|<=|S|-1`. \(\square\)

This is the correct dynamic interpretation: the closed four-cycle state
exists before the switch, while the one-cycle state is opened only at the
terminal rooted forest.  Choosing the opened `H2` paths as the terminal
`Q` state would make four paths and remove four q1 tickets; it would also

## 3. Exact q3/q4 hierarchy arithmetic and regeneration

A forward q-port fusion changes the component count by `-(q-1)`.  Hence
every `{3,4}` hierarchy obeys

\[
                         c-1=2N_3+3N_4.                 \tag{3.1}
\]

The q4-dominant minimum packet counts are

\[
\begin{array}{c|c|c}
c\bmod3&N_4&N_3\\ \hline
1&(c-1)/3&0\\
0&(c-3)/3&1\\
2,\ c\ge5&(c-5)/3&2.
\end{array}                                             \tag{3.2}
\]

They use `ceil((c-1)/3)` packets.  The case `c=2` needs another actuator.
Parity is automatic:

\[
                         N_4\equiv c-1\pmod2,           \tag{3.3}
\]

so the successor sign is `(-1)^(c-1)`.

The frozen q-port is depth one.  Each `H2` port rail plus direct edge is an
entire saturated component; after fusion the large `H3` component contains
no proper old port cycle.  Therefore (3.1)--(3.3) are component arithmetic,
not an iteration theorem.

### Theorem 3.1 (weakest regenerative socket theorem)

Suppose a rooted `{3,4}` merge tree is supplied with the following literal
data at every internal node.

1. Each child exports a distinct oriented lower-to-tail socket rooted by
   the same current predecessor phase; the child interiors are disjoint.
2. The child sockets form the old `H2` state of a q-port, and the `H3`
   rewrite has the same complete immediate palettes and produces the
   declared parent socket.
3. The parent socket survives until its parent is used.  No two incomparable
   nodes consume one occurrence, and every serial reuse is an explicit
   child-output/parent-input identification.
4. Every run touching a rewritten adjacency passes the literal depth-`d`
   suffix/prefix test.  Runs wholly inside a child have already been
   certified.
5. Every old interval witness crossing a rewritten block either survives or
   has a named occurrence outside all later modifications.  The terminal
   complete-reversal cut is paid by its overlap/Ferrers payload; arbitrary
   q-port cuts instead obey the exact occurrence inequality
   `N_+(T)>=mu_c(T)`.
6. The one final orientation has the required endpoint/voltage state and a
   literal terminal compiler matching.

Then postorder application of the packets produces one resident component
whenever (3.1) has a solution.  It preserves every owner and immediate
palette once and loses no old upper target.  Conversely, every serial
q-port schedule with no split/rebuild outside its declared packets induces
such a socket tree.

#### Proof

At a node, the q-port theorem gives the component contraction, common
immediate resources and internal residence for the literal standard rails.
For those unsubstituted rails it also gives the local setwise inclusion

\[
                         Deck(H_2)\subseteq Deck(H_3).   \tag{3.4}
\]

After arbitrary child interiors are substituted, (3.4) is not a contextual
transparency theorem.  Items 3--5 are precisely the additional occurrence-
level hypotheses which replace that unjustified inference: every interval
meeting a substituted block or splice is replayed or given a protected
outside witness.  Induction over postorder then proves the first assertion
and sums the decrements to (3.1).  The terminal matching is needed only at
the root in the global-reversal quotient.  Conversely, record the actual
component coarsenings, consumed sockets, surviving witnesses and output
sockets of a successful schedule; they satisfy items 1--6. \(\square\)

Under the stronger resource-private implementation, the hierarchy reserves

\[
                         (2d+2)(4N_4+3N_3)              \tag{3.5}
\]

owner atoms.  Failure of (3.5) rules out that private implementation, not a
recycling socket construction.

For exactly seven input cycles the attractive closed topology is

\[
                   7\xrightarrow{q4}4\xrightarrow{q4}1. \tag{3.6}
\]

Both rewrites preserve the complete immediate palettes.  If the second
node is genuinely regenerative, one opens only the final cycle, so the
optimal path loses one lower-q1 colour without solving a seven-cut colour
recycling problem.  The depth-one theorem says precisely why (3.6) is not
yet furnished by two standalone frozen packets: the first fused component
must export a *new* parent-ready socket used at the second node.

## 4. A proof-safe locality obstruction for residence repair

The tempting dimension-free `2q` locality bound is false.  Equal coordinate
bits at an old and a new seam do not preserve run-component identity: a
fusion may splice runs which previously belonged to different cycles.

### Lemma 4.1 (exact old-run incidence of a literal q-port fusion)

In the standard rank-`m` `H2 -> H3` q-port fusion, exactly `qm` old positive-
run components are incident with the rewrite when constant traces are
counted.  In particular at most `qm` old short-run components can be
destroyed.  Of these, exactly `q(d+1)` are nonconstant in the canonical
unsubstituted rail.

#### Proof

The deleted direct arcs are `A_i->B_i`, and the predecessor of `B_i` changes
from `A_i` to `A_(i+1)`.  Every coordinate in the rank-`m` head `B_i` is
therefore incident with one altered old positive-run component.  For a
coordinate in `S`, runs from distinct old cycles are re-paired; for `a_i` a
former `1-1` join is cut; and for `a_(i+1)` a former run start is joined to
the preceding component.  The only tail-only coordinate is
`z in A_i-B_i`; since `z` is also absent from `B_(i-1)`, its positive run
still ends at `A_i` and is unchanged.  The `q` heads have disjoint old
component incidences, giving `qm`.

In one canonical port the affected nonconstant runs are the `d` filler
runs `x_j` and the one `a_(i+1)` P-half run.  They all have length `d+1`,
so their total is `q(d+1)`. \(\square\)

The lemma concerns an already installed literal packet.  A larger interior
replacement or the planting of the packet may touch many more hazards and
must advertise that support in its socket signature.

### Corollary 4.2 (fusion-only residence no-go for the seven-component host)

For seven components, a monotone `{3,4}` hierarchy ending in one component
has either

\[
                         (N_4,N_3)=(2,0)
             \quad\hbox{or}\quad(0,3).                 \tag{4.1}
\]

At `k=17`, where `m=9`, the two branches can destroy at most `72` and `81`
old short-run components respectively.  Starting from the independently
opened baseline of `5760`, at least `5688` remain in the q4 branch and at
least `5679` remain in the q3 branch.

#### Proof

Equation (3.1) becomes `6=3N4+2N3`, whose nonnegative solutions are exactly
(4.1).  Lemma 4.1 gives `2*4*9=72` and `3*3*9=81`.  Each altered old run can
remove at most one member of the old short-run census. \(\square\)

The scope is essential.  The required `H2` packet sites are assumed already
present, and the only edits counted are the forward q-port rethreads.  If
one first **plants** those sites by changing other factor edges, those
planting edits may touch many more runs and lie outside the corollary; they
must be charged as the interior repair columns of Section 5.

Therefore q3/q4 by itself is a topology actuator, not an all-purpose
residence repair.  An interior circuit/rethread layer must remove the bulk
hazards while preserving or exporting the q-port sockets.

## 5. The exact seven-component joint completion gate

Let `F` be a protected owner/lower/immediate-upper exact factor with cycle
components `K_1,...,K_7`.  A **guarded repair column** records, literally:

* its removed and inserted owner adjacencies and all lower/upper-q1 currents;
* the old residence hazards it destroys and every new hazard it creates;
* the rank-eleven-through-rank-thirteen witnesses gained or lost;
* its protected-owner and fixed-`M0` resource use;
* its input and output q3/q4 socket types, including `d`-step endpoint trace
  states; and
* its exact effect on the terminal compiler occurrence graph.

### Theorem 5.1 (joint repair--join--compiler criterion)

A finite collection of guarded columns followed either by ordinary
component seams or by a closed regenerative tree such as (3.6) gives a
valid one-oriented Hamilton source if and only if the following conditions
hold.  If the columns are component-neutral and leave the original seven
components, the ordinary route uses six seams.  In general it uses
`c_after_columns-1` seams and its component-current ledger must use that
actual number.

1. **Physical current:** every owner has the required in/out degree and
   every retained lower colour is used once.  In the component-neutral
   seven-component ordinary route, six seams recycle six of the seven cut
   colours.  In the regenerative
   route all internal fusions are palette-neutral and only the final opening
   omits one colour.  In either route exactly one lower colour is absent at
   the two global boundaries.
2. **Topology:** the component/socket current is a rooted spanning tree and
   the realized owner order has no subtour.
3. **Residence:** every old short run is destroyed, no selected column or
   seam creates a short run, and every new endpoint join passes its full
   `d`-state trace test.
4. **Upper witnesses:** every immediate upper colour and every required
   higher target has at least one surviving or newly created interval
   witness.  Witnesses are occurrence-labelled, not only mask-labelled.
5. **Compiler:** on the resulting single maximal-erosion word, the exact
   target--cell graph has a target-saturating matching satisfying all pins,
   guards and deadlines.

#### Proof

Necessity is literal.  For sufficiency, apply the balanced columns, follow
the spanning component current to obtain the unique owner path, and use
Conditions 3--4 to certify its residence and upper deck.  Maximal erosion
then gives the source word, and Condition 5 supplies its lower compiler.
No other row is used. \(\square\)

The theorem explains why the remaining k17 rows must be solved jointly.
Opening/joining a frozen seven-cycle factor can recycle q1 colours, but it
cannot alter thousands of wholly internal short runs.  Conversely, an
interior residence rethread can destroy unique higher witnesses or the
compiler unless its column carries those ledgers.

### 5.2 Exact incidence-C6 loose-hypertree criterion

Let `K` have rank `m-2`, and choose three labels `a,b,c` outside `K`.  Put

\[
 L_a=K+a,\quad L_b=K+b,\quad L_c=K+c,
\]

and

\[
 O_{ab}=K+a+b,\quad O_{bc}=K+b+c,\quad O_{ca}=K+c+a.
\]

The incidence hexagon has complementary matchings

\[
\begin{aligned}
 E_0&=\{L_aO_{ab},L_bO_{bc},L_cO_{ca}\},\\
 E_1&=\{L_aO_{ca},L_bO_{ab},L_cO_{bc}\}.              \tag{5.1}
\end{aligned}
\]

If `E0` is selected, `E1` is absent, and the three edges of `E0` lie on
three distinct factor components, the toggle `E0 -> E1` fuses those three
components into one.  The inverse statement holds with the phases swapped.
This is just the alternating-C6 splice, but (5.1) fixes its literal Boolean
resources.

For three initially available packets let `T_i` be their triples of old
component labels.  They form a **protected literal loose hypertree** when

1. every removed incidence is unprotected and every inserted incidence is
   absent;
2. their literal lower and old/new owner supports are pairwise disjoint;
3. after reordering,
   `|T_1|=3`, `|T_2 cap T_1|=1`,
   `|T_3 cap (T_1 union T_2)|=1`, and
   `T_1 union T_2 union T_3` is the full seven-component set; and
4. the rank-ten ticket (5.3) below is nonnegative after every prefix.

Under these conditions the toggles commute on incidences, and their
component trajectory is exactly

\[
                            7\longrightarrow5
                             \longrightarrow3
                             \longrightarrow1.          \tag{5.2}
\]

Conversely, any three initially available, resource-disjoint C6 fusions
with trajectory (5.2) induce such an ordered loose hypertree.  This
equivalence does not cover a later C6 created by an earlier toggle, nor an
overlapping circuit which removes and restores the same protected resource.

### 5.3 Exact palette, residence and deep-witness tickets

At a toggled lower vertex `L`, let `V(L)` be its unchanged other incident
owner, and let `O^-(L),O^+(L)` be the removed and inserted owners.  For a
rank-ten target `R`, define

\[
 \Delta_e(R)=\sum_{L\in e}
 \bigl(1_{V(L)\cup O^+(L)=R}-1_{V(L)\cup O^-(L)=R}\bigr). \tag{5.3}
\]

For a resource-disjoint batch `A`, rank-ten exactness after a prefix is
equivalent to the literal inequalities

\[
                         \mu_0(R)+\sum_{e\in A}\Delta_e(R)\ge1
                         \qquad\text{for every }R.       \tag{5.4}
\]

Thus (5.4), not a count of changed colours, is the exact q1 ticket.

Residence also has a finite exact ticket.  Cut every affected component at
its modified lower vertices.  For each resulting owner-word block and each
coordinate, record whether its trace is all one, its leading and trailing
one-run lengths clipped at `d+1`, and the counts of wholly internal one-runs
of lengths `1,...,d`.  Concatenation updates only the two boundary runs, so
these data form an associative finite-state monoid.  Closing the last
boundary gives the exact cyclic residence ledger; opening it gives the
exact linear ledger.  In particular single-packet residence deltas are not
safe to add unless the intervening fragment states are also matched.

For upper ranks eleven through thirteen use the stronger block signature

\[
                  \Sigma(B)=(\operatorname{tot}B,
                    \operatorname{Pref}B,
                    \operatorname{Suf}B,
                    \operatorname{Deck}B).              \tag{5.5}
\]

For concatenated blocks `LR`, its exact multiplication is

\[
\begin{aligned}
 \operatorname{tot}(LR)&=\operatorname{tot}L\cup\operatorname{tot}R,\\
 \operatorname{Pref}(LR)&=\operatorname{Pref}L\cup
     \{\operatorname{tot}L\cup P:P\in\operatorname{Pref}R\},\\
 \operatorname{Suf}(LR)&=\operatorname{Suf}R\cup
     \{S\cup\operatorname{tot}R:S\in\operatorname{Suf}L\},\\
 \operatorname{Deck}(LR)&=\operatorname{Deck}L\cup
     \operatorname{Deck}R\cup
     \{S\cup P:S\in\operatorname{Suf}L,
                    P\in\operatorname{Pref}R\}.         \tag{5.6}
\end{aligned}
\]

After the final cyclic suffix--prefix multiplication, a target ticket is
valid exactly when its mask occurs in the resulting deck.  Masks already
above rank thirteen may be replaced by an overflow symbol, because unions
never decrease rank.  Equations (5.5)--(5.6) are therefore an exact compact
witness oracle for the current rank-eleven--thirteen gate; fixed-width or
local-gain proxies are not.
