# Audit of stabilizer-root bipartization and surplus current

## 1. Stabilizer-root cut

A subgroup \(H\le C_n\) of order \(h\) is generated by the shift
\(\ell=n/h\).  Since \(n\) is odd, \(h,\ell\) are odd.  The \(H\)-orbit of
the boundary between positions \(\ell-1\) and \(\ell\) consists of \(h\)
edges and cuts the coordinate cycle into \(h\) paths of order \(\ell\).

The weight

\[
 \chi_H(t)=\sum_{j,p}p\,t_{j,p}\pmod2
\]

is invariant under \(H\).  An internal path transfer changes it by one;
a deleted-boundary transfer changes it by \(\ell-1\), which is even.
Therefore the bipartition and same-shore classification really descend
to the simple quotient.  A nonloop quotient edge cannot simultaneously
have internal and boundary representatives, since that would make it
both reverse and preserve the descended parity.

## 2. Burnside replay

An element of order \(d\mid h\) has \(h/d\) cycles of length \(d\) on
the path components.  A fixed state has mass divisible by \(d\).  Because
\(d\) is odd, both its mass and parity reduce to one representative from
each component cycle.  Its signed enumerator is therefore

\[
 [z^{R/d}]
 \left(
   \prod_{p=0}^{\ell-1}(1+(-1)^p z+z^2)
 \right)^{h/d}.
\]

There are \(\varphi(d)\) group elements of order \(d\).  This gives the
displayed divisor sum exactly.  For \(\ell=2m+1\), pairing one even and one
odd coordinate factor gives

\[
 (1+z+z^2)(1+z^2+z^4)^m.
\]

Every coefficient is nonnegative and the identity term is positive at
every attainable odd mass, so the majority-shore sign is correct.

## 3. Minority-saturating quotient matching

For a fixed orbit of pair-sum/key data, its stabilizer is an odd subgroup
of \(H\).  The active two-state keys form a hypercube modulo that subgroup.
The odd-group quotient theorem gives a perfect matching of every fibre
with at least one active key.  The only unmatched fibres have every pair
in \(00,20,22\).

With either displayed root phase, each quiet pair contributes even
\(\chi_H\), and the unpaired coordinate also has even weight.  Hence all
unmatched orbits lie on the majority shore.  The constructed matching
saturates the minority shore, so the number of unmatched orbits equals
the Burnside difference.

This step does not claim hub-rainbow selection.  It is a matching in the
simple quotient sector, and the theorem correctly sends repeated hub
colours to the existing fan/receiver layer.

## 4. Cotransversal and exchange checks

The transversal matroid on the majority shore has full rank equal to the
minority-shore size.  Duality gives rank equal to the shore difference.
A difference-sized set is a dual basis exactly when its complement is
matched bijectively to the minority shore.  The rank formula in the note
is the standard dual-rank identity with transversal rank evaluated as a
maximum matching number.

The union of two minority-saturating matchings is a disjoint union of
alternating cycles, even alternating paths, and common unmatched
vertices.  Every nontrivial path joins an endpoint unmatched by the first
matching to one unmatched by the second.  Flipping any subset of these
disjoint paths independently gives exactly the Boolean exchange family in
the note.  Common unmatched vertices are fixed, so the number of distinct
bases is \(2^{|Q^-\setminus Q^+|}\), not necessarily \(2^{\Delta_H}\);
the theorem uses the corrected statement.

Finally, if a boundary matching covers all elements of one such surplus
basis except an optional socket, adjoining it to the complementary
nonwrap matching is literal and proves the completion theorem.  The
converse is exact only for the stated majority-only current architecture;
the note does not suppress minority-shore same-shore edges in an arbitrary
perfect matching.

## 5. Particle-pair ear check

With one zero and one two inserted in a fixed linear run of \(L\) ones,
one orientation has state set

\[
 \{(i,j):1\le i<j\le L\},
\]

of size \(\binom L2\).  Every annihilating boundary state returns to the
same lower-shell parent.  A closed odd ear at that parent has an even
number of internal vertices.  Since \(\binom L2\) is odd for
\(L\equiv2,3\pmod4\), independent one-parent closed ears cannot cover the
oriented fibre in those congruence classes.  This is only a no-go for the
fibrewise shell scheme; cross-parent ears remain possible.

## 6. Final scope

The note proves a new stabilizer-aware bipartization, an exact orbit
current formula, minority saturation, and a cotransversal/two-base
completion criterion.  It does not prove:

1. the boundary-edge matroid matching;
2. unpointed hub-rainbow selection;
3. paired receiver Hall/Tutte extension;
4. cross-level PBBS compatibility; or
5. the all-\(k\) upper bound.

No complete-transfer adjacency, labelled-to-quotient descent, or
hub-capacity shortcut is used.
