## 6. Fail-closed filtering rules

For an octahedral output `Q`, the currently proof-safe order is:

1. reconstruct the eight immutable incidences and final physical atlas;
2. apply exact physical/declared-face and five-coordinate zero-265 gates;
3. apply the root separator (2.1); a disjoint packet is
   `REJECT_Q1_CERTIFIED_ROOT_FAN_PERSISTS`;
4. if `Q` meets the root cone, rebuild the socket roles and complete local
   arm table.  Failure to escape rejects; escape only promotes;
5. apply another stored core/Hall certificate only after exact content-keyed
   row equality or a typed guarded-minor/Hall embedding with complete final
   provider and blocker replay; and
6. absent a complete `L0/Lsucc` epoch, label every remaining row `UNKNOWN`,
   not `PASS_STATIC_FILTER`, `LIBRARY_OPEN`, or q1 feasible.

In particular:

* mask equality, provider-degree equality, changed-slot overlap, and a
  changed numeric component id are not persistence/escape proofs;
* a missing stored guarded-minor clause or implication arc proves at most
  `OPEN_MANIFEST` relative to a declared complete derivation list; it is not
  semantic non-entailment;
* an incomplete embedding list, hash drift, absent outside blocker, or
  unproved Hall packing bound is `UNKNOWN`; and
* no SAT launch is licensed merely by passing the available static rows.
  The zero-265/library sieve must first be complete enough to produce a
  genuinely small, replayable survivor set.

This audit does not close the octahedral face and makes no rank-11+, global
residence, topology, common-cap, or compiler claim.
