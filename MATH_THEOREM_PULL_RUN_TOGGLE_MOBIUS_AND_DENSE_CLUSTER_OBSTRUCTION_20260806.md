# Pull-run toggles: exact Möbius language and a dense-cluster obstruction

## Status

Core-coordinate pull runs give genuine partial packet trades while fixing
the complete owner and both immediate palettes.  Their lower occurrence
support is not arbitrary: it is a principal ideal in the cyclic interval
poset.  This note gives the exact zeta/Möbius characterization for scalar
run multiplicities and a literal labelled characterization coordinate by
coordinate.

In particular, a generic dense subset of one packet is not toggleable.  The
set of all proper interval occurrences except one singleton is an explicit
density-`1-o(1)` obstruction.  Thus a mesoscopic alteration theorem may use
pull toggles only after proving that its dense clusters lie in the interval-
ideal language.

## 1. The interval poset

Let a cyclic source ring have period `L`, owner width `D=d+1`, and distinct
private phase labels.  Assume

\[
                              L\ge D+2.                     \tag{1.1}
\]

Let `mathcal I` be the poset of all nonempty cyclic phase intervals of
length at most `d`, ordered by containment.  There are

\[
                              |\mathcal I|=Ld                \tag{1.2}
\]

occurrence positions.

For `I in mathcal I`, write

\[
                       \mathcal T(I)=\{J\in\mathcal I:J\subseteq I\}.      \tag{1.3}
\]

This is the triangular principal ideal generated by `I`, of size

\[
                              |\mathcal T(I)|={|I|(|I|+1)\over2}.          \tag{1.4}
\]

## 2. Exact literal toggle

Start from an all-high source word

\[
                              A_t=K\cup\{f_t\}.             \tag{2.1}
\]

Fix `x in K` and a cyclic run `I` of length at most `d`.  In the pulled
phase replace (2.1) by

\[
 A_t'=
 \begin{cases}
 (K-\{x\})\cup\{f_t\},&t\in I,\\
 K\cup\{f_t\},&t\notin I.
 \end{cases}                                               \tag{2.2}
\]

### Theorem 2.1 (principal-ideal toggle)

The move (2.1)--(2.2) preserves:

1. every rank-`r` owner;
2. every immediate-lower root;
3. every immediate-upper colour; and
4. cyclic state balance.

A proper interval occurrence `J` changes if and only if `J subseteq I`.
More precisely,

\[
 \bigcup_{t\in J}A_t'=\left(\bigcup_{t\in J}A_t\right)-\{x\}
     \quad\Longleftrightarrow\quad J\in\mathcal T(I).       \tag{2.3}
\]

#### Proof

No omission run contains `D` phases.  Hence every owner window contains a
phase outside `I`, where `x` remains present.  The owner row is unchanged;
its intersections and unions, the two immediate palettes, are therefore
unchanged as well.  Both source words are cyclic, so state balance is
automatic.

The coordinate `x` is absent from an interval union precisely when it is
absent at every phase of that interval, namely when `J subseteq I`.  This
is (2.3).  \(\square\)

For distinct core coordinates with runs `I_x`, the effects superpose
literally:

\[
 \bigcup_{t\in J}A_t'
 =\{f_t:t\in J\}\cup
   \bigl(K-\{x:J\subseteq I_x\}\bigr).                     \tag{2.4}
\]

There is no hidden interaction term.

## 3. Zeta and Möbius characterization

Let `a_I` be the number of core coordinates assigned the one-run omission
`I`.  The number of omitted coordinates seen by occurrence `J` is

\[
                              z(J)=\sum_{I\supseteq J}a_I.  \tag{3.1}
\]

Thus `z` is the upper-zeta transform of `a` on the interval poset.

### Theorem 3.1 (exact scalar one-run language)

An integer profile `z:mathcal I -> Z` is a signed integer combination of
pull triangles if and only if its Möbius coefficients

\[
                              a_I=\sum_{J\supseteq I}\mu(I,J)z(J)          \tag{3.2}
\]

are integers.  Since `z` is integral, this is automatic, and the
coefficients are unique.

It is a one-polarity multiplicity profile using at most `c=|K|` distinct
one-run coordinates if and only if

\[
                              a_I\ge0\quad\text{for all }I,
 \qquad\sum_Ia_I\le c.                                    \tag{3.3}
\]

It is a difference of two such phases if and only if

\[
 \sum_I(a_I)_+\le c,\qquad
 \sum_I(a_I)_-\le c.                                      \tag{3.4}

Here the interval-poset Möbius function is local.  If `I^L,I^R,I^{LR}`
denote extension of `I` by one phase on the left, right, or both sides,
with nonexistent intervals interpreted as zero, then

\[
                    a_I=z(I)-z(I^L)-z(I^R)+z(I^{LR}).       \tag{3.5}

#### Proof

Equation (3.1) is the zeta transform on a finite poset, hence has the unique
inverse (3.2).  The interval `[I,J]` in the containment poset is a product
of the two chains which extend the left and right endpoints.  The Möbius
function of a chain is nonzero only across zero or one step.  Its product
gives (3.5).

Nonnegative `a_I` are exactly the multiplicities of physical omission
runs; their sum is the number of required distinct core coordinates.  For
a signed difference, place the positive coefficients in the second phase
and the negative coefficients in the first.  This proves (3.3)--(3.4).
\(\square\)

Formula (3.5) is the exact finite list of inequalities for a proposed
scalar cluster: all mixed second endpoint differences must have the
required sign, and their total mass must fit the core.

## 4. Boolean support language

If only the support of changed occurrences is recorded, a family of
one-polarity pull runs changes

\[
                              C=\bigcup_x\mathcal T(I_x).    \tag{4.1}
\]

### Corollary 4.1 (support iff downset)

With no bound on the number of core coordinates, a subset
`C subseteq mathcal I` is the support of a one-polarity pull family if and
only if it is a downset in the interval-containment poset.  With core size
`c` and one run per coordinate, it is realizable if and only if it has at
most `c` maximal intervals.

#### Proof

Every principal ideal is a downset, and unions preserve that property.
Conversely every finite downset is the union of the principal ideals of its
maximal elements.  \(\square\)

The scalar multiplicity condition (3.3) is stronger than support
realizability: overlapping principal ideals change a common subinterval in
more than one labelled coordinate.

## 5. A smallest dense obstruction

Fix one singleton phase interval `J_0` and put

\[
                              C=\mathcal I-\{J_0\}.          \tag{5.1}
\]

Then

\[
                              {|C|\over|\mathcal I|}=1-{1\over Ld}.        \tag{5.2}
\]

### Theorem 5.1 (dense cluster no-go)

The set (5.1) is not the support of any one-polarity pull family, regardless
of the number of available core coordinates.

#### Proof

Choose any interval `J` of length two containing `J_0`.  Then `J in C` but
its subinterval `J_0` is not in `C`, so `C` is not a downset.  Apply
Corollary 4.1.  \(\square\)

Thus density, even density `1-o(1)`, is irrelevant to pull-toggle
realizability.

## 6. Consequence for mesoscopic packet reservoirs

A mesoscopic alteration which outputs an arbitrary dense subset
`C subseteq e` of one packet cannot invoke pull superposition as a generic
`C` versus `e-C` actuator.  It must first prove one of the following:

1. `C` is a downset of the packet's cyclic interval poset;
2. its desired scalar multiplicity profile satisfies (3.3);
3. its signed two-phase profile satisfies (3.4); or
4. an additional non-pull trade supplies the missing Möbius coefficients.

Owners and both immediate palettes are free throughout this test.  The
obstruction is entirely the exact lower occurrence language.
