# Exact fixed-edit SAT neighborhoods for a 476-entry `k=11` one-hole word

Date: 2026-07-24

## Scope

This is an exact replacement-value solver for a supplied collection of edit
position sets of size at most six.  For every supplied set it simultaneously
searches all `2047^r` assignments of nonzero 11-bit values without enumerating
that Cartesian product.

The outer selection of position sets is heuristic.  Therefore an UNSAT result
closes exactly the listed sets and is not a radius-`r` no-go theorem.  A SAT
model is materialized and independently checked by quadratic interval-OR
enumeration and both existing C++ verifiers before it may improve the upper
bound.

## 1. Exact fixed-position reduction

Let the seed be (W=(W_0,\ldots,W_{n-1})), and fix the editable positions

\[
E=\{e_0<e_1<\cdots<e_{r-1}\},\qquad r\le 6.
\]

Write (X_i\in\{1,\ldots,2047\}) for the replacement at (e_i).  Values are
allowed to equal their seed values, so one fixed set represents every change
support contained in that set.

Delete the positions in (E).  Every interval avoiding (E) lies wholly in
one of the resulting (r+1) segments.  Direct suffix-OR enumeration within
those segments computes the exact repair family

\[
\mathcal R(E)=\{t:\text{no old witness interval for }t\text{ avoids }E\}.
\tag{1}
\]

Targets outside \(\mathcal R(E)\) retain a literal old witness under every
assignment to the editable positions.

### Consecutive-block lemma

If an interval meets (E), the indices of the edit positions that it meets
form one nonempty consecutive block

\[
e_a,e_{a+1},\ldots,e_b.
\tag{2}
\]

Indeed, if it contains (e_i) and (e_j) with (i<j), convexity of an
integer interval forces it to contain every (e_s\) with (i<s<j).  Conversely
every nonempty intersection has a unique first and last edit index.  Hence
there are only

\[
\frac{r(r+1)}2\le21
\tag{3}
\]

edit categories, not (2^r-1) arbitrary subsets.

For an interval (I) of category ([a,b]), put

\[
B_I=\bigvee_{p\in I\setminus E}W_p.
\]

Its new OR is exactly

\[
B_I\vee X_a\vee X_{a+1}\vee\cdots\vee X_b.
\tag{4}
\]

For a target (t), equation (4) equals (t) iff

1. (B_I\subseteq t);
2. (X_i\subseteq t) for every (a\le i\le b);
3. every bit of (t\setminus B_I) occurs in at least one of
   (X_a,\ldots,X_b).

Thus a witness pattern is described by only

\[
(a,b,N),\qquad N=t\setminus B_I.
\tag{5}
\]

All intervals producing the same triple have identical replacement
constraints.  For fixed ((a,b)), if two realized need masks satisfy
(N_1\subset N_2), the (N_2) term is redundant in the disjunction, so only
inclusion-minimal need masks are retained.

## 2. CNF encoding and iff theorem

One case uses at most (11r\le66) primary value bits.  For each retained
pattern (5), introduce a witness variable (w).  It implies:

- every outside bit of every (X_i), (a\le i\le b), is false;
- for every bit in (N), at least one (X_i) in the block supplies it.

For every (t\in\mathcal R(E)), one retained pattern must be active.  Each
replacement value receives a nonzero clause.

This CNF is satisfiable iff some assignment of nonzero values at the positions
in (E) makes the complete word universal:

- If a universal assignment exists, each target in \(\mathcal R(E)\) has a
  final witness.  That witness cannot avoid (E), by (1), so its unique
  consecutive block and fixed base produce one encoded pattern satisfying all
  of the implications.
- Conversely, every encoded pattern is generated by at least one actual seed
  interval.  Its bit constraints make that interval's repaired OR exactly its
  target.  Targets outside \(\mathcal R(E)\) retain their untouched witnesses,
  so all 2,047 nonzero masks occur.

Many position cases are batched in one formula.  Each case has disjoint value
and witness variables and a gating selector.  A sequential at-most-one
encoding plus the selector disjunction chooses exactly one case.  This is
equisatisfiable with a plain disjunction of cases because activating or
deactivating one case cannot affect any other case's private variables.

## 3. Position-set selection

For every current hole (h), the selector enumerates every seed interval
having at most the requested radius of contaminating entries

\[
C_h(I)=\{p\in I:W_p\not\subseteq h\}.
\tag{6}
\]

If a repaired word witnesses (h) on (I), every member of (C_h(I)) must
be editable.  These contaminators are therefore mandatory.  The enumerator
deduplicates equal mandatory patterns.  It also retains several low-load
possible creator positions from clean portions of the intervals; when the
mandatory set is empty, at least one such creator is required.

The remaining repair positions are beam-filled using an exact, simultaneous
addition ledger.  Suppose the current set is (E).  For a represented target
(t), retain the old witnesses avoiding (E).  Adding a new position (p)
destroys the last untouched witness of (t) iff (p) lies in every retained
witness.  Since all witnesses are intervals, their common intersection is
again an interval

\[
\left[\max_I \ell(I),\,\min_I r(I)\right].
\tag{7}
\]

A range-add over (7), for every target, gives the exact new repair-family size
for all 476 possible additions in one pass.  Beam ranking first minimizes this
exact size and then the number of unique seed witnesses touched.

The enumeration of (6) is exhaustive, but retaining only a bounded number of
creator variants and beam states is intentional.  The emitted position-set
portfolio is therefore a high-value selected neighborhood, not every set of
three through six positions.

## 4. Independent checks

`decode_verify_k11_fixed_edit_neighborhood.py` reads a SAT model, selects an
active case, reconstructs its replacement values from only the primary bit
variables, materializes the word, and independently enumerates all

\[
\binom{477}{2}=113{,}526
\]

nonempty intervals quadratically.  It does not inspect or trust any witness
variable.

The wrapper then also runs

```text
/root/verify_or_array 11
/root/verify_or_suffix 11
```

and creates `.VERIFIED` only if all three checks return zero.

The separate randomized oracle
`audit_k11_fixed_edit_neighborhood_logic.py` compares, on small words, the
pattern/base screen against direct word materialization for every tested value
tuple.  It separately compares (7) with direct recomputation after every
possible added position.  This test is run on RunPod, not on the local Mac.

## Status

This work gives a sound, compact, practically deployable exact value solver
for selected 3--6-position neighborhoods.  It does not establish that no
universal 476-entry word exists, and it does not change the certified bound

\[
465\le \nu(11)\le477.
\]
