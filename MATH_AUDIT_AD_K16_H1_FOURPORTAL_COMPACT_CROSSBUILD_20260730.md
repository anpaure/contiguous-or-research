OR, so a residual literal interval cannot cross a block.  Every residual
target has exactly one undominated form for every one of the 29 nonempty
local block intervals and no cross-block form.

active target family is automatically nonzero, and omitting that coordinate

targets supplies every selected residual need; a cell used by no selected

witnesses.  This proves the reduction in both directions.

As a further independent closure check, the meet-semilattice generated by
the 55 residual targets has exactly 215 nonzero elements.  Adding the unused
cell value `0xffff` gives a 216-value canonical alphabet.  This is a genuine
WLOG finite alphabet for the unbounded-cardinality model **inside the fixed
joint13 support**.  It is not a proof that an arbitrary global solution can
be moved into this support, and it does not make the 153 minimum-debt portal
values a WLOG restriction.
